# 체형·목적 기반 AI 코디 추천 프로젝트 파이프라인

## 1. 사용자 정보 입력

사용자가 다음 정보를 선택하거나 입력한다.

- 전신사진
- 키와 체중(선택)
- 원하는 스타일
- 코디 목적: 데일리, 데이트, 출근, 여행 등
- 예산
- 유지하고 싶은 옷: 상의, 하의 또는 전체 변경

사진은 정면 전신이 보이고 몸과 옷의 경계가 명확한 이미지를 사용한다.

## 2. 체형 및 자세 분석

MediaPipe Pose 등을 이용해 어깨, 골반, 허리, 무릎, 발목 위치를 찾는다.

이를 바탕으로 다음과 같은 상대적인 비율을 계산한다.

- 어깨와 골반의 비율
- 상체와 하체의 비율
- 다리 길이 비율
- 전체적인 실루엣과 자세

사진만으로 실제 신체 치수를 정확하게 측정하기는 어려우므로, 절대적인 수치가 아닌 코디 추천에 필요한 참고 정보로 사용한다.

## 3. 현재 착장 분석

의류 분석 모델을 이용해 사용자가 입고 있는 옷의 특징을 파악한다.

- 상의·하의 종류
- 색상과 색 조합
- 옷의 길이와 핏
- 패턴과 소재
- 전체적인 스타일
- 체형과의 조화

이 단계에서는 의류 파싱 모델과 FashionSigLIP 같은 패션 이미지 모델을 함께 활용한다.

## 4. 변경할 코디 범위 결정

사용자의 목적과 현재 코디를 바탕으로 어떤 부분을 변경할지 결정한다.

- 현재 코디를 유지하고 보완점만 안내
- 상의만 변경
- 하의만 변경
- 상의와 하의를 모두 변경
- 필요하면 신발이나 가방까지 추가 추천

항상 한 가지 요소만 바꾸는 것이 아니라, 전체적인 조화를 위해 필요한 범위만큼 변경한다.

## 5. 코디 후보 탐색

패션 전문가의 의견을 정리한 규칙 데이터와 실제 쇼핑몰 상품을 이용해 후보를 찾는다.

- 체형 보완 효과
- 상·하의 색상 조화
- 사용 목적과 스타일
- 기존에 유지할 옷과의 조화
- 가격과 재고
- 계절과 날씨

쇼핑몰 상품은 가능한 경우 공식 API나 제휴 서비스를 이용하고, 크롤링이 필요한 경우에는 해당 사이트의 이용약관과 이미지 사용 범위를 확인한다.

## 6. 추천 후보 순위 결정

각 후보에 점수를 매겨 가장 적합한 코디를 선정한다.

`체형 적합도 + 색상 조화 + 목적 적합도 + 사용자 취향 + 상품 조건`

사용자에게는 단순히 점수만 보여주는 것이 아니라 추천 이유를 함께 제공한다.

> 짧은 기장의 상의가 상체와 하체의 비율을 더 균형 있게 보여줄 수 있어요. 현재 바지와 어울리도록 밝은 무채색 계열을 선택했어요.
> 

## 7. 가상 피팅 이미지 생성

선정된 상의와 하의를 사용자의 전신사진에 합성한다. 두 옷을 모두 변경한다면 가능하면 다중 의류를 한 번에 처리할 수 있는 VTON 모델을 사용한다.

이미지를 여러 장 미리 생성하지 않고 다음 방식으로 처리한다.

1. 빠른 설정으로 결과 1장을 우선 생성
2. 얼굴·체형·자세가 유지됐는지 자동 검사
3. 옷의 색상·패턴·형태가 제대로 반영됐는지 검사
4. 결과가 기준에 미달할 때만 1장을 추가 생성
5. 사용자가 원하면 ‘다시 생성’ 기능 제공

합성되는 동안에는 코디 설명과 추천 상품을 먼저 보여줘 체감 대기시간을 줄인다.

## 8. 최종 결과 제공

최종 화면에는 다음 내용을 함께 보여준다.

- 현재 코디 분석
- 추천 코디와 가상 착용 이미지
- 상의와 하의를 변경한 이유
- 추천 상품명·가격·구매 링크
- 비슷한 대체 상품
- 다른 결과 보기 버튼

가상 피팅 이미지는 실제 핏을 보장하는 결과가 아니라 코디의 전체적인 분위기를 확인하기 위한 참고 이미지라는 점도 안내한다.

## 9. 사용자 피드백 반영

사용자의 반응을 저장해 이후 추천에 활용한다.

- 마음에 들어요
- 별로예요
- 저장
- 다른 스타일 요청
- 실제로 입어본 뒤의 만족도

초기에는 전문가 규칙을 중심으로 추천하고, 데이터가 충분히 쌓이면 사용자 피드백을 활용해 추천 순위 모델을 개선한다.

## 데이터 수집

1·2단계 개발과 검증에 쓸 정면 전신 사진은 [collect/](collect/)의 자동 수집
파이프라인으로 모은다. 유튜브 룩북 영상에서 정면·전신·서 있는 자세 프레임만
골라 성별 폴더로 저장한다.

```bash
python -m pip install -r collect/requirements.txt
python collect/setup.py
python collect/discover_channels.py --verify --write
python collect/collect.py --target 50
python collect/qa.py --move
```

결과는 `data/images/{male,female}/`, 출처 기록은 `data/manifest*.csv`에 남는다.
자세한 필터 기준과 한계는 [collect/README.md](collect/README.md) 참고.

## 개발 순서

1. 전신사진 체형·착장 분석
2. 전문가 패션 규칙 데이터 구축
3. 규칙 기반 코디 추천
4. 쇼핑몰 상품 검색 및 추천
5. 가상 피팅 기능 추가
6. 자동 품질 검사와 조건부 재생성
7. 사용자 피드백 기반 개인화 추천 고도화
