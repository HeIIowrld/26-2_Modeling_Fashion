## 2. 평가 구성과 발견한 문제

### 평가 구성

- 사람 12명, 상품 48개: 상의 24개·하의 24개.
- 12명 모두 상의 평가: **288쌍**.
- 하의 평가가 가능한 8명: **192쌍**. 합계 **480쌍**.
- 같은 하의 192쌍에서 마스크만 넓힌 대조 실험 추가.
- CatVTONTryOn.fast(): DPM++ 2M Karras, 25스텝, 생성 시드 42, augmented 속성 헤드 사용.
- 핏 정답은 모델 추정 카탈로그 `fit`이 아닌 판매자 태그 `detail_fit` 사용.
- 하의 표본에 섞인 반바지 3개는 핏 분석에서 제외. 긴바지 핏 비교는 **168쌍**이며 품질·기장 경고 분석에는 원래 192쌍을 사용.

### 3:4 사진의 합성 실패 수정

960×1280 등 3:4 사진은 입력 비율이 모델과 같아 패딩이 생기지 않는데, 생성 결과 크기를 원본으로 복원하지 않아 후속 처리에서 실패했다. **크기 복원 로직과 회귀 테스트를 추가**했다.

이 변경과 최초 평가 자료는 커밋 `9eedc5d`, PR #22를 통해 `main`의 `f578cce`에 병합됐다.

발목 관측 여부만을 기준으로 삼았을 때는 4명이 제외돼 **96조합**이 보류됐다. 무릎과 실제 밑단을 활용하는 판정 경로를 추가해 1명의 **24조합을 다시 검사 가능**하게 했다.

남은 3명은 `1-model_3`, `model_5`, `model_7`이다. 실제 바지 픽셀이 영상 마지막 행까지 이어져 밑단을 관측할 수 없다. 사진에 없는 부분을 임의로 추측해 검사 통과로 처리하지 않았다.

밑단이 포함된 사진이나 사용자가 입력한 현재 기장을 이용하면 남은 사례도 비교할 여지가 있다. **추가 사진 요청·사용자 기장 입력 기능은 아직 구현하지 않았다.**

## 5. 시도했지만 채택하지 않은 개선안

### 선택적 하의 마스크 확장

기존 기본/확장 결과를 이용해 상품명에 와이드·벌룬·배기·커브드 등이 있는 긴바지만 확장 결과를 선택하는 정책을 계산했다. **새로 전체 조합을 합성한 실험이 아닌 사후 분석**이다.

- 긴바지 168쌍에서 자기 상품 식별 top-1: **38.7%→45.8%**.
- 하지만 슬림·레귤러 판매자 태그 상품도 결과 폭이 **+0.046 [0.020, 0.074]** 늘어남.
- 동일한 기본 마스크 밖의 PSNR 중앙값: **47.59→37.89dB**.
- 의도한 확장 영역의 변화도 이 PSNR 감소에 포함되므로 모두 시각적 손상으로 해석하지는 않음.

슬림·레귤러 상품의 폭이 늘지 않아야 한다는 합격 조건을 충족하지 못해 **기본 동작으로 채택하지 않았다.** 판매자의 전체 핏 태그와 실제 바지통 형태가 다른 개념이라는 평가상의 한계도 남겼다.
