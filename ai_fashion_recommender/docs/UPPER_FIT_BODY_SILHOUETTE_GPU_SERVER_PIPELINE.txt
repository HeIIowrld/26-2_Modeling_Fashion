6-1. 핵심 CV 연구 주제: 확률적 신체 라인 분포 추정
======================================================================

이 단계가 프로젝트의 핵심 Computer Vision 기여다.

문제 정의

  P(hidden body contour | RGB, pose, garment mask, visible skin, fit posterior)

즉, "오버핏이면 몸이 이 정도일 것이다"라는 고정 규칙을 쓰는 것이 아니라 다음 관측을
결합해 옷 아래 신체가 존재할 가능성을 픽셀별 또는 높이별 분포로 출력한다.

입력
  - 사용자 RGB 이미지
  - 상의·하의 의류 segmentation mask
  - 피부·손·발·얼굴 등 관측 가능한 신체 mask
  - MediaPipe 관절 heatmap
    상체: 어깨 / 팔꿈치 / 손목 / 골반
    하체: 골반 / 무릎 / 발목
  - 핏 모델의 단일 label이 아니라 클래스별 posterior probability
    예: {슬림: 0.03, 레귤러: 0.08, 여유: 0.24, 오버: 0.65}
  - 각 관절 visibility와 quality head 결과

출력
  - body occupancy probability map: H×W, 각 픽셀이 신체 내부일 확률
  - body centerline heatmap: 몸통 중심과 좌우 팔다리 중심선 확률
  - 높이별 좌우 경계 분포
    left_x(y)  ~ Normal(mu_left(y), sigma_left(y))
    right_x(y) ~ Normal(mu_right(y), sigma_right(y))
  - 단면별 반폭 분포
    상체: shoulder / chest / waist / hip / upper-arm / forearm
    하체: hip / thigh / knee / calf / ankle
  - body_proxy_confidence
  - 관절 누락, 가림, 측면 자세 등에 따른 uncertainty

손목·발목의 역할
  - 손목과 발목은 몸통 폭을 직접 정하는 값이 아니다.
  - 팔·다리 중심선의 끝점과 방향을 정하고, 보이는 손/발 영역과 결합해 소매·바짓단 아래의
    신체 위치를 제한한다.
  - 팔꿈치·무릎은 굽은 팔다리의 경로를 정한다.
  - 어깨·골반은 몸통과 사지 폭을 정규화하는 주요 anchor다.

확률 분포가 필요한 이유
  - 두꺼운 옷 아래 실제 경계는 사진만으로 하나의 정답으로 확정할 수 없다.
  - 오버핏·와이드일수록 sigma를 크게 하고, 슬림핏이나 피부가 보이는 구간은 sigma를 작게 한다.
  - 생성 마스크는 목적에 따라 확률 등고선을 다르게 사용할 수 있다.
    body core: 높은 확률 영역
    target garment envelope: 중간 확률 영역 + 목표 핏 여유
    안전한 erase 영역: 현재 옷 전체 영역
  - confidence가 낮으면 분포를 억지로 좁히지 않고 기존 마스크로 fallback한다.

권장 모델 구조

  Branch A: Fit encoder
    FashionSigLIP RGB/masked RGB 특징 + geometry
    -> upper_fit 또는 bottom_silhouette posterior

  Branch B: Pose/visibility encoder
    관절 Gaussian heatmap + visibility map + skin/hand/foot mask

  Branch C: Garment encoder
    현재 의류 mask + 거리 변환(distance transform) + RGB feature

  Fusion decoder
    A/B/C 특징을 결합한 작은 U-Net 또는 heatmap decoder
    -> occupancy logits
    -> centerline heatmaps
    -> boundary mean/log-variance

처음부터 생성모델 전체를 재학습하지 않는다. FashionSigLIP과 pose/parser는 우선 동결하고,
핏 head와 작은 body-proxy decoder를 학습한다. 필요할 때만 일부 블록을 LoRA로 미세조정한다.

6-2. 숨겨진 신체 정답 데이터 만드는 방법
======================================================================

헐렁한 옷 사진에는 숨겨진 실제 신체 경계 정답이 없으므로 사람이 상상해서 라벨링하면 안 된다.
다음 pseudo-supervision을 사용한다.

A. 보이는 신체/타이트한 착장 기반 pseudo ground truth
  - 슬림핏 상의, 레깅스, 스키니 등 신체 윤곽이 상대적으로 잘 보이는 사진을 모은다.
  - pose + human parser + 관측 경계로 body proxy 정답을 만든다.
  - 피부가 실제로 보이는 팔·발목 구간은 높은 신뢰도 anchor로 기록한다.

B. Synthetic loose-garment occlusion
  - A의 body proxy 정답은 그대로 유지한다.
  - 의류 마스크만 여유/오버/세미와이드/와이드/벌룬 형태로 인공 확장한다.
  - RGB에는 실제 옷 texture를 합성하거나 마스크 기반 occlusion augmentation을 적용한다.
  - 모델은 넓어진 옷 외곽이 아니라 원래 body proxy 분포를 복원하도록 학습한다.

C. Paired consistency
  - 동일 인물이 타이트한 옷과 헐렁한 옷을 입은 paired 사진이 있으면 사용한다.
  - 포즈를 정렬한 두 이미지의 body proxy가 지나치게 달라지지 않도록 consistency loss를 준다.

D. 선택 사항: SMPL/가상 인체
  - 이용 허가된 3D 인체 렌더가 있으면 실제 body silhouette 정답을 보조 데이터로 사용한다.
  - 실제 사진 도메인과 차이가 있으므로 단독 학습 데이터로 사용하지 않는다.

따라서 body line 단계도 수작업으로 숨은 몸을 그리는 대규모 라벨링보다, 관측 가능한 타이트
착장 + synthetic occlusion을 이용하는 것이 현실적이다.

권장 loss

  total_loss = fit_classification_loss
             + occupancy_bce_dice_loss
             + centerline_heatmap_loss
             + boundary_gaussian_nll
             + uncertainty_calibration_loss
             + paired_consistency_loss

평가 지표
  - occupancy IoU / Dice
  - 좌우 경계 MAE(어깨·골반 폭 또는 신장으로 정규화)
  - centerline PCK
  - Gaussian NLL
  - 50%/80%/90% 예측 구간 coverage
  - uncertainty calibration error
  - downstream VTON의 목표 핏 일치율과 원래 옷 잔류율

필수 ablation
  - B0: pose only
  - B1: pose + segmentation
  - B2: pose + segmentation + fit posterior
  - B3: pose + segmentation + fit posterior + RGB feature
  - B4: B3 + learned uncertainty

핏 정보를 추가했을 때 B1보다 B2/B3의 경계 오차, calibration, downstream VTON이 실제로
개선되는지 확인해야 "핏 인식이 신체 라인 추정에 도움을 줬다"고 주장할 수 있다.

7. 상체 Body Proxy 구현
======================================================================

팀원 코드에서 재사용할 것

  src/outerwear_top_tryon.py
    - build_outerwear_top_masks()
    - OuterwearTopMasks
    - erase_mask / target_body_mask / outer_ring / protected_mask 분리
    - FLUX 외투 제거와 선택적 2차 생성

변경할 것

1) target_width_scale(product)의 상품명 휴리스틱을 주 경로로 쓰지 않는다.

   기존:

2) 사용자의 current upper_fit도 context에 전달한다.

   outfit_analyzer.py
     -> upper_fit label/confidence/quality
   web/pipeline.py
     -> VTON context에 fit 결과 전달
   outerwear_top_tryon.py
     -> current fit에 따라 관측 의류 경계 신뢰도 조절

3) target_body_mask를 공용 body_proxy_mask로 승격한다.

   기본 입력:
     - left/right shoulder
     - left/right elbow
     - left/right wrist
     - left/right hip
     - 보이는 피부/손
     - 현재 상의 segmentation
     - current upper_fit + confidence

4) 세 영역을 끝까지 분리한다.

   source_erase_mask
     기존 외투/상의 전체를 지우는 영역

   body_proxy_mask
     관절을 따라 추정한 몸통·팔의 생성 가이드

   target_garment_envelope
     새 상품의 핏과 기장에 맞게 옷을 그릴 목표 영역

5) 2-pass 권장

   Pass 1
     부피가 큰 기존 외투를 제거하고 외투 바깥쪽은 배경으로 복원

   Pass 2
     body proxy + target envelope 위에 새 상의를 생성

8. 하체 Body Proxy 구현
======================================================================

기존 코드

  catvton_tryon.py
    - long_bottom_mask(): 긴 바지용 convex hull
    - shape_lower_mask(): 상품 바지가 더 넓을 때만 마스크 확장

한계
  - 현재 와이드 바지를 목표 스트레이트로 좁히는 경우를 직접 해결하지 못함
  - 넓은 현재 바지의 옆부분을 실제 다리 공간으로 오인할 수 있음

새 함수 권장

  build_lower_body_proxy()
  fit_aware_lower_mask()

입력
  - left/right hip
  - left/right knee
  - left/right ankle
  - 현재 lower_style_mask
  - current bottom_silhouette + confidence
  - target bottom_silhouette + confidence
  - target bottom_length

출력
  - 현재 바지 전체 source_erase_mask
  - 좌우 관절 중심선을 따르는 두 개의 leg body proxy
  - 목표 핏별 target garment envelope
  - uncertainty/fallback 사유

목표 envelope 예시
  - 슬림: 관절 중심 가까이 좁게
  - 스트레이트: 무릎부터 밑단까지 폭 변화가 작게
  - 세미와이드: 허벅지와 밑단을 중간 폭으로
  - 와이드: 허벅지부터 밑단까지 넓게
  - 벌룬: 허벅지·무릎은 넓고 밑단은 다시 좁게
  - 플레어: 무릎 아래부터 확장

와이드 현재 바지 → 스트레이트 목표 바지는 2-pass 우선 실험

  Pass 1: 기존 와이드 바지 전체와 옆 잔상을 지우고 배경/공간 복원
  Pass 2: leg body proxy와 스트레이트 envelope 위에 새 바지 생성

10. 실험 설계와 배포 승인 기준
======================================================================

최소 A/B

  A0: 기존 CatVTON 마스크
  A1: 팀원 pose 기반 상체 target_body_mask
  A2: fit class + pose 기반 상·하체 body proxy
  A3: fit class + pose + 상품 이미지 target envelope + 2-pass

평가 세트
  - 최소 50~100명/사진
  - 오버핏 상의, 모피/패딩/롱코트
  - 와이드→스트레이트, 슬림→와이드 등 방향별 변환
  - 정면 외에도 허용 범위의 자세와 가림 사례
  - 상품과 사용자의 성별/카테고리 오류가 없는 고정 세트

필수 지표
  - target fit 재분류 정확도
  - 원래 핏 잔류율
  - 관절 중심 보존
  - 배경 복원 오류율
  - 얼굴·손·하의·신발 보존율
  - 상품 디테일 재현
  - 사람 평가: 자연스러움/핏 충실도/상품 충실도

배포 전 통과 조건
  - 단위 테스트 전체 통과
  - 사람 검수 test set에서 user/shop 양쪽 성능 확인
  - 기존 A0보다 주요 실패율이 악화되지 않음
  - 모피/패딩/와이드 사례에서 개선이 반복 재현됨
  - 실패 시 기존 경로로 fallback됨
  - API 응답에 body proxy를 신체 치수로 노출하지 않음

환경 플래그 권장

  FASHION_BODY_PROXY_MODE=off|pose|fit_pose
  FASHION_UPPER_BODY_PROXY=1
  FASHION_LOWER_BODY_PROXY=1
  FASHION_BODY_PROXY_CHECKPOINT=<body_proxy_heads.pt 절대경로>

처음에는 기본값 off로 배포하고 내부 검증 후 fit_pose로 전환한다.
