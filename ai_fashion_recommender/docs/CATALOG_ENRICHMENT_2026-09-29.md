실측표가 바지인데 상의로 등록된 `MS6830180`을 발견했다. 카탈로그 원문은 유지하고 오프라인 추천 후보에서 제외한다. 알 수 없는 실측 타입은 잘못된 분류라고 단정하지 않는다.

실측표 확보는 실제 착용 가능성이나 재고 확인을 뜻하지 않는다. 기존 사이즈 15% 축은 잘 맞는 기준 옷의 같은 실측 항목과 비교한다. 사진·신체 둘레를 의류 단면으로 변환하지 않으며 1시간 이상 된 옵션 재고는 미확인으로 처리한다.

## 색상 결과

- 2,224개 옵션 응답을 모두 처리했고, 834개에서 명시적인 색 옵션 이름을 얻었다. 상품명/기존 색을 포함한 `color_options`가 있는 상품은 1,888개다. 이 수치는 1,888개의 색 옵션을 API에서 새로 받았다는 뜻이 아니다.
- `COLOR_CHIP` 외에 `DROPDOWN`의 명시적 `colorCode`도 읽도록 수정했다. 삭제된 옵션은 제외한다. 사이즈·임의 선택 옵션을 색으로 해석하지 않는다.
- 상품명에 한 색만 있거나 모든 색 옵션이 동일한 팔레트로 해석될 때만 대표 색을 확정한다. 첫 컬러칩으로 대표 색을 임의 선택하지 않는다. 기존 카탈로그 색 1,843개는 보존했다.
- 색상 미상 229개 전체의 대표 사진을 AI로 시각 검토했다. 195개를 사진 판정으로 기록했고, 그중 2개는 새 API 근거가 있어 최종 출처가 카탈로그다. 기존 사진 판정 152개는 보존했다.
- 여러 색의 팩·다색 상품 또는 판정이 불확실한 34개는 비워 뒀다. 사진 판정은 판매자 제공 사실이나 사람이 검증한 정답으로 표시하지 않는다. 임의 신뢰도 점수를 만들지 않았으며 회피 색 하드 필터에 사용하지 않는다.
- 검토 대상의 404 이미지 URL 26개를 해당 상품의 최신 상세 응답에서 복구하고 사진을 확인했다. 카탈로그 이미지 주소도 갱신했다.

`data/product_photo_color_review.csv`에 판정 방식, 검토 시각, 상품 ID, 출처 URL, 검토 이미지 해시를 남겼다. 원본 사진은 `outputs/catalog_backfill/review_images/`에 있다.
