1. 데이터 폴더 준비 — CPU Mac
======================================================================

권장 구조

  ai_fashion_recommender/data/fit_vision/
    images/
      user_bottom/
      shop_bottom/
      user_top/
      shop_top/
    masks/                 # GPU 스크립트가 생성
    annotations.csv        # 라벨링 페이지가 생성

사진 조건
  - 사람이 실제로 착용한 사진을 사용한다.
  - 하의는 골반부터 밑단까지 보여야 한다.
  - 상의는 양쪽 어깨, 몸통, 소매와 밑단이 보여야 한다.
  - 평면 누끼 상품은 quality=평면 상품으로 표시하며 v1 핏 학습에서는 제외한다.
  - 동일 상품의 여러 모델컷은 같은 product_id/group_id로 묶는다.
  - 동일 사용자의 같은 착장은 같은 person_id+outfit_id/group_id로 묶는다.

데이터 출처 원칙
  - 팀원/본인 사진은 촬영·연구 활용 동의를 받은 것만 사용한다.
  - 공개 데이터셋은 라이선스가 연구 목적 사용과 로컬 보관을 허용하는지 확인한다.
  - Fashionpedia/DeepFashion 계열은 원본 핏 라벨이 없으므로 이미지 풀로만 활용한다.
  - 쇼핑몰 상품 사진은 서비스 약관과 재배포 조건을 확인하고 학습 데이터는 저장소에
    commit하지 않는다.
  - 상품명에 적힌 핏은 임시 힌트일 뿐 gold label로 자동 확정하지 않는다.

첫 실험 권장 수량
  - 하의 스트레이트 200장
  - 하의 세미와이드 200장
  - 하의 와이드 200장
  - user 사진과 shop/model 사진이 한쪽으로 치우치지 않게 구성

이 3-class 경계가 검증된 다음 skinny/slim/balloon/flare와 상의 클래스를 확장한다.


======================================================================
2. CPU 라벨링 페이지 실행
======================================================================

저장소의 ai_fashion_recommender 폴더에서 실행한다.

  cd ~/Documents/26-2_Modeling_Fashion/ai_fashion_recommender

shop 하의

  ../.venv-web/bin/python scripts/label_fit_vision.py \
    --images-dir data/fit_vision/images/shop_bottom \
    --dataset-root data/fit_vision \
    --output-csv data/fit_vision/annotations.csv \
    --category bottom \
    --source-domain shop

user 하의

  ../.venv-web/bin/python scripts/label_fit_vision.py \
    --images-dir data/fit_vision/images/user_bottom \
    --dataset-root data/fit_vision \
    --output-csv data/fit_vision/annotations.csv \
    --category bottom \
    --source-domain user \
    --group-regex '(P[0-9]+_O[0-9]+)'

user 파일명 예시
  P001_O001_front.jpg
  P001_O001_side.jpg

위 두 장은 정규식에 의해 같은 group으로 묶여 반드시 같은 split에 들어간다.
파일명 규칙이 다르면 --group-regex를 실제 규칙에 맞게 바꾼다.

라벨링 원칙
  - 핏과 기장을 별도로 선택한다.
  - 스트레이트/세미와이드 경계가 애매하면 억지로 정답을 만들지 않는다.
  - 가림, 측면·교차 자세, 잘림, 평면 상품, 판정 불가를 quality에 표시한다.
  - 20~30%는 다른 팀원이 중복 검수하고 불일치 사진만 제3자가 확정한다.

서버 종료
  - 라벨링 페이지를 실행한 터미널에서 Ctrl+C

5. GPU 환경 점검
======================================================================

권장
  - Python 3.11
  - NVIDIA GPU
  - CUDA 사용 가능한 PyTorch

확인

  nvidia-smi
  python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'NO CUDA')"

torch.cuda.is_available()가 False면 학습을 시작하지 않는다.
PyTorch는 해당 GPU/드라이버에 맞는 CUDA 설치 명령을 PyTorch 공식 설치 선택기에서 받아
먼저 설치하고, 그 다음 프로젝트 의존성을 설치한다.

  python -m pip install -r ai_fashion_recommender/requirements.txt

Hugging Face 모델을 처음 받을 때는 인터넷 연결이 필요하다. 모델 캐시가 있다면 해당 캐시를
함께 복사할 수 있다. 비공개 토큰은 코드나 Git에 넣지 않는다.

======================================================================
7. GPU 작업 2 — FashionSigLIP 임베딩 캐시 생성
======================================================================

  mkdir -p outputs/fit_vision

  python scripts/train_fit_vision.py cache \
    --annotations-csv data/fit_vision/annotations.csv \
    --image-root data/fit_vision \
    --train-cache outputs/fit_vision/train.pt \
    --val-cache outputs/fit_vision/val.pt \
    --device cuda \
    --batch-size 32

메모리 부족 시 --batch-size를 16 또는 8로 낮춘다.
이 캐시는 frozen FashionSigLIP 특징이므로 다섯 ablation에서 재사용한다.


======================================================================
8. GPU 작업 3 — 5개 ablation 학습
======================================================================

동일한 train/val cache로 아래 feature mode를 각각 학습한다.

  rgb_only
  masked_only
  rgb_mask
  rgb_geometry
  rgb_mask_geometry

명령 예시

  python scripts/train_fit_vision.py train \
    --train-cache outputs/fit_vision/train.pt \
    --val-cache outputs/fit_vision/val.pt \
    --output-checkpoint outputs/fit_vision/rgb_mask_geometry.pt \
    --feature-mode rgb_mask_geometry \
    --device cuda \
    --epochs 40 \
    --batch-size 128 \
    --learning-rate 0.001

feature-mode와 output-checkpoint 이름만 바꾸어 5회 실행한다.
각 체크포인트 옆의 *.metrics.json을 보관한다.

우선 비교할 지표
  - bottom_silhouette macro_f1
  - 스트레이트 F1
  - 세미와이드 F1
  - 와이드 F1
  - by_domain.user macro_f1
  - by_domain.shop macro_f1

전체 정확도만 높은 모델은 채택하지 않는다. user 또는 shop 한쪽에서 무너지는 모델도 제외한다.


======================================================================
9. 첫 배포 체크포인트
======================================================================

첫 v1은 rgb_mask_geometry가 RGB baseline보다 실제로 좋아졌을 때만 채택한다.
채택한 head 파일을 아래 위치에 둔다.

  models/fit_vision_heads.pt

다른 위치를 쓰려면 서버 실행 전에 지정한다.

  export FASHION_FIT_VISION_HEADS_PATH=/절대경로/fit_vision_heads.pt

서버 재시작 후 사용자 착장 분석과 무신사 상품 샘플 재랭킹이 같은 체크포인트를 자동 사용한다.
