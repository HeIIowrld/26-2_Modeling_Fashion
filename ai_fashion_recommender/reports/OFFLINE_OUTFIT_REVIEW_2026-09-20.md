# 코디 사전 계산 결과 재검토

## 결론

점수 인덱스와 조회는 동작한다. 그러나 실제 합성에서는 상품의 바지통·밑단 형태가
달라진 사례가 확인됐다. 자동 품질 검사 통과만으로 상품의 핏까지 검증됐다고 볼 수 없다.
합성된 이미지의 점수를 해당 상품 조합의 추천 점수로 채택하기 전에 상품 반영 검사를
보완해야 한다.

## 확인 시점의 작업 상태

- 예상 점수: 100만 조합 × 216개 조건 = 2억 1,600만 개 저장 완료.
- 최초 GPU 작업 `232154`: 정상 종료, 9분 46초.
- 실제 합성: 12건 완료. 서로 다른 상품 조합은 4개이며 여러 대표 사진에 적용한 결과다.
- 추가 작업 `232156`: `PENDING (Priority)`. 아직 시작하지 않아 실행 로그도 없다.
- 전체 계획 320건 중 보유 사진의 체형·하체 비율·성별 조건을 충족하는 계획은 187건.
  나머지 133건은 해당 조건의 대표 사진이 없다. 실행 기록에는 그중 먼저 확인된 6건만
  `missing_reference`로 남아 있으며, 아직 처리하지 않은 계획은 302건이다.

이 확인 과정에서 작업을 취소하거나 점수 배열·원본 실행 결과를 변경하지 않았다.

## 이미지 비교

합성 이미지 4장과 해당 상품 원본을 비교했다. 남성의 원래 착장 사진도 함께 확인했다.
이는 첫 12건 전체에 대한 육안 검수가 아니다.

| 비교 사례 | 관찰한 문제 |
| --- | --- |
| 와이드 치노 → 남성 역삼각체형 사진 | 상품은 밑단이 넓고 길지만 결과는 발목 밴드가 있는 조거 형태다. 원래 착장의 조거 밑단과 비슷한 형태가 남았다. |
| 같은 와이드 치노 → 여성 사각체형 사진 | 바짓가랑이와 옆선이 과도하게 처진 형태로 변했다. 원래 상품의 와이드 실루엣과 다르다. |
| 브라운 와이드 팬츠 → 남성 역삼각체형 사진 | 원본은 넓은 일자 밑단이지만 결과는 발목으로 좁아진다. 캐시의 해당 예시 점수는 86.002다. |
| 와이드 치노와 흰 반팔 → 여성 역삼각체형 사진 | 바지통이 좁아졌고 팔 쪽에 원래 의복으로 보이는 회색 조각이 남아 있다. |

원래 착장의 마스크 범위가 생성 형태를 제한하는 것으로 보이지만, 이 문서에서는
원인 분리 실험까지 수행하지 않았다. 색상은 상품 사진 자체가 어두운 청색이므로
인식 결과의 `블루 → 블랙` 차이만으로 합성 색상 실패라고 단정하지 않는다.

## 검사 결과와의 불일치

첫 12건의 자동 검사 기록에는 실패 항목이 없다. 하지만 위 이미지 비교에서는
상품 핏과 밑단 불일치가 확인됐다. 따라서 기존 보고의 ‘자동 품질 검사 통과’를
상품 충실도에 대한 육안 검수 통과로 해석해서는 안 된다.

남성 치노 결과는 후속 인식에서 `조거·스웨트팬츠`로 분류됐다. 다른 결과는
`하렘 팬츠`로 분류되거나 종류 판정이 보류됐다. 이 신호가 현재 완료 상태 판정에는
반영되지 않는다. 또한 신발 점수는 상품 속성 기준이므로 합성된 신발의 시각적
일치도가 검증된 점수는 아니다.

현재 고득점 합성 후보의 순위는 ‘실제 상품을 충실히 반영한 코디의 순위’로
확정할 수 없다. 필요한 보완은 상품·합성 간 종류와 밑단 형태 확인, 실패 결과의
추천 제외, 적절한 대표 착장 선정이다. 대표 사진이 없는 133건의 조건도 별도로
보충해야 한다.
