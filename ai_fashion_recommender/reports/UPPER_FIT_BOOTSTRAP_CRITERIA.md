# 상의 핏 3종 학습 기준

## 라벨 정의

상의 핏은 보이는 가장 바깥 의류가 몸통과 팔의 윤곽에 비해 얼마나 여유가 있는지를 기준으로 판정한다. 기장은 별도 축이므로 크롭 여부는 핏 라벨을 바꾸지 않는다.

| 라벨 | 판정 기준 | Fashionpedia 속성 | 대표적인 시각 단서 |
|---|---|---|---|
| 슬림핏 | 몸통과 팔에 가깝게 붙고 여유분이 작음 | `tight (fit)` | 가슴·허리 윤곽이 드러남, 소매 폭이 좁음 |
| 레귤러핏 | 몸을 조이지 않으면서 표준적인 여유가 있음 | `regular (fit)` | 어깨선이 대체로 제 위치, 몸통 폭이 보통 |
| 오버핏 | 몸통·소매에 큰 여유가 있거나 의도적으로 크게 설계됨 | `loose (fit)`, `oversized` | 드롭 숄더, 넓은 몸통, 큰 소매와 여분의 부피 |

스키니·테이퍼드처럼 하의에서 쓰던 세부 용어는 상의에 적용하지 않는다. `loose`와 `oversized`는 사용자가 정한 3종 체계에서 모두 오버핏으로 통합한다.

## 레이어드 정책

| 상황 | 화면에 표시할 핏 | 바디라인 추정에서의 취급 |
|---|---|---|
| 상의 한 벌 | 해당 상의 핏 | 일반 신뢰도로 사용 |
| 닫힌 아우터 + 이너 | 가장 바깥 아우터 핏 | 몸통 윤곽의 직접 증거로는 낮게 신뢰 |
| 열린 아우터 + 보이는 이너 | 가장 바깥 아우터 핏 | 이너의 보이는 경계는 보조 단서로만 사용 |
| 여러 겹이거나 경계가 불명확 | 가장 바깥에서 지배적으로 보이는 옷의 핏 | 불확실성을 높이고 신체 폭을 단정하지 않음 |

첫 학습 데이터는 레이어 혼동을 줄이기 위해 단일 상의 사진만 사용한다. Fashionpedia는 상의 계열 인스턴스가 정확히 하나인 사진만 포함하고, DeepFashion-MultiModal은 공식 상의 마스크가 있으면서 아우터 마스크가 없는 사진만 포함한다. 레이어드 사진은 별도 사람 검수 세트가 마련된 뒤 추가한다.

## 학습과 사용 범위

Fashionpedia 라벨은 데이터셋의 명시적 핏 속성을 정답으로 사용한다. DeepFashion-MultiModal은 핏 정답이 없으므로 FashionSigLIP과 마스크 기하로 만든 약한 라벨이며 사람 검수가 필요하다. 모든 표본은 출처, 라벨 생성 방식, 겹쳐입기 상태를 CSV와 manifest에 기록한다.

이 모델의 출력은 옷의 관측 핏 확률이다. 출력만으로 실제 신체 폭을 확정하지 않고, 포즈·노출된 피부·의류 마스크와 함께 신체 경계의 불확실성을 조절하는 신호로 사용한다.
