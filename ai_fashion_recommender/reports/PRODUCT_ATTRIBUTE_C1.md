같은 저장 예측에서 상품명 라벨이 빈 축에만 사진 라벨을 넣은 **오프라인 시뮬레이션**이다. 검색 배선·순위 개선 결과가 아니다.

전체 평가 가능 281개 속성에서 일치 수는 60→156으로 늘지만, 새로 채운 155개 중 59개는 틀린 라벨이다. 빈 예측을 오답으로 세는 정확도 하나만 보면 이 문제가 가려진다.

판단에 사용한 구체적인 한계는 다음과 같다.

- **평면컷 핏:** `MS6955600`의 판매자 레귤러핏을 슬림핏으로, `MS7122627`의 판매자 레귤러핏을 오버핏으로 판정했다. 상의 평면컷에서 사진이 새로 채운 핏은 4개 중 1개만 일치했다.
- **소재:** `MS7144038`은 판매자가 코튼 95%로 명시했지만 사진 헤드는 니트로, 코튼 팬츠 `MS6907192`는 데님으로 판정했다. 이 축을 보충 입력으로 사용할 근거가 없다.
- **착용컷 하의 핏:** 추가 라벨 19/19가 참조와 일치해 후속 검증 후보로 남긴다. 다만 하의 착용컷 32개 중 26개가 와이드핏이고, AI 참조 라벨이라는 한계가 있다.
- **기장:** 하의 착용컷 32개가 모두 긴바지다. 항상 긴바지라고 답해도 32/32이므로 사진 모델의 구별 능력을 검증한 결과로 해석할 수 없다. 평면컷 기장도 평가 가능 표본이 3개뿐이다.

이 결과를 바탕으로 C-2에서는 기존 FASHN 파서로 착용 흔적을 확인하고, 신뢰도 0.90 이상인 핏·기장만 보충했다. 같은 100개에서 평가 가능한 새 판정 16개가 모두 AI 참조와 일치했다. 종류·소재·신발은 사진 보충 대상에서 제외했다. 별도 검증 표본을 확보하지 않았으므로 일반화된 정확도 개선으로 단정하지 않는다.

## 데이터와 재현

- [AI 참조 라벨 100개 CSV](attribute_c1/labels_ai_reviewed.csv), [사진별 검수 기록](attribute_c1/ai_visual_review.json), [판매자 근거](attribute_c1/labels_ai_reviewed.sources.json).
- [원시 사진·상품명 예측](attribute_c1/predictions.json), [속성별 400개 비교 기록과 집계](attribute_c1/accuracy_ai_reviewed.metrics.json), [추가 사진 출처](attribute_c1/supplemental_sources.json).
- 종류는 판매자 분류와 기존 `catalog_derivation.json`의 공통 어휘를 사용했다. 핏·기장은 사진과 판매자 정보로 판단하고, 평면컷 일부는 별도 착용 사진을 확인했다. 모델은 기존 대표 사진만 받았다.
- 소재는 겉감·갑피의 소재군이다. 코튼은 판매자 근거를 요구했고, 니트·데님·스웨이드 등은 사진의 구조와 판매자 정보를 대조했다. 가죽은 천연/합성을 구분하지 않는다. 모호한 소재 38개는 `unknown`이다.
- 소재를 포함해 라벨 집합 완전 일치로 집계한다. `unknown`과 `not_applicable`은 양쪽 모두 제외하고, 모델 보류·미지원은 오답으로 센다. `other`는 어휘 밖의 실제 품목/소재이며 평가에 포함한다.
- 사진 판정은 서버 체크포인트로 `predict(image, tasks=...)`를 그대로 호출했다. 판매자 정보로 모델 출력을 덮어쓰지 않았다. 모델 재학습·교체는 없다. C-2는 같은 헤드를 재사용하는 검색 코드 변경이며 운영 서버에는 배포하지 않았다.
- 예측 수집 당시 서버 헤드 SHA-256: `3c560c9db0ade6a62d3ead1fc61edc56ff6a935083ee7393858a3a757431765d`. 코드·백본·입력 해시는 예측 JSON에 기록했다.
- 고정 어휘에 대한 `_score()` 일치 평가다. 실제 사용자 질의별 추천 정확도나 순위 정확도를 뜻하지 않는다. 인기 목록 표본이므로 전체 카탈로그의 대표 표본으로 일반화할 수 없다.

다음 명령은 네트워크·GPU 없이 동일한 표와 비교 기록을 다시 만든다.

```bash
python3 ai_fashion_recommender/scripts/evaluate_attribute_c1_ai_review.py report \
  --labels ai_fashion_recommender/reports/attribute_c1/labels_ai_reviewed.csv \
  --predictions ai_fashion_recommender/reports/attribute_c1/predictions.json \
  --output /tmp/attribute_c1_reproduced.md
```
