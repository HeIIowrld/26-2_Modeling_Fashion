# 핏 생성 경로 보강 (2026-09-28)

기준은 GitHub `main`의 `f746d0b`이다. 이번 변경은 핏 전환 편집 영역과 목표 상품의 핏 근거를 보강한다. 운영 서비스나 모델 체크포인트는 교체하지 않았다.

## 변경

- 몸선 prior의 `plausible_mask`는 위치 추정일 뿐 편집 허가 영역이 아니다. 상의 전환에서는 상의·팔·몸통 피부, 하의 전환에서는 하의·다리 라벨에 속한 픽셀만 추가한다. 기존 전환 마스크가 의도적으로 포함한 상의 밑단 겹침은 유지한다.
- 목표 상품의 핏은 판매자 `detail_fit` 태그를 우선한다. 태그가 없고 상품명에 충돌 없는 핏 단서가 있으면 이름을 사용하며, 둘 다 없을 때 카탈로그 `fit`을 사용한다. `Product.seller_fit`에 원본 태그를 보존한다.
- 현재 카탈로그 2,224개 중 새 근거 순서로 전환 경로가 달라지는 상품은 100개(상의 70, 하의 30)다. 이 숫자는 이미지 품질 개선 건수가 아니라 입력 라벨 선택의 변경 건수다.

## 검증

- 로컬 관련 단위·통합 테스트 85개 통과. 상의 전환 prior가 기존 마스크 밖의 바지 픽셀을 새로 편집하지 않고, 하의 전환 prior가 상의 픽셀을 편집하지 않는지 확인했다.
- 격리된 서버 복사본에서 생성 관련 테스트 68개 통과했다. 이 검증은 판매자 태그 필드를 추가하기 전 코드에 대한 것이며, 필드 추가 후에는 로컬 테스트를 재실행했다.
- 동일 인물 `model_8`·상품 `MS6931285`·시드 42의 GPU 비교에서 원본 좌표의 하의 편집 마스크가 156,274 → 154,131픽셀로 줄었지만 최종 이미지는 동일했다. 이 사례는 화질 향상 근거가 아니다.
- 상품명과 사진은 와이드 바지인데 카탈로그 `fit`이 슬림인 `MS7118322` 사례도 비교 대상으로 준비했다. GPU 작업 `248533`은 다른 작업의 메모리 사용으로 대기해 취소했다. 이 상품에서 새 경로가 실제 와이드 실루엣을 더 잘 만드는지는 아직 확인하지 못했다.

다음 판정은 같은 사람·상품·시드로 기존 경로와 새 경로를 비교하고, 상품 바지통·기장·상의 보존·얼굴 보존을 함께 검수해야 한다. 이 결과 전에는 이미지 품질이 개선됐다고 주장하거나 운영본을 전환하지 않는다.
