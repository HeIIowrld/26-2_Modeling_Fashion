# 기장·핏 변경 시 피부와 배경 복원 — 2026-09-24

## 변경과 원인

GitHub `main`을 확인하고 로컬 `f7c0b7e`에서 `2f56d70`으로 fast-forward했다.
추가 변경은 PR #49의 배포 스모크 단계 순서 수정 두 파일이었다. 기존 PR #48의
체형 가림 검사는 분석 단계에 적용돼 있었지만, VTON의 옷 윤곽 문제를 해결하지는 않았다.

CatVTON의 입력 마스크는 현재 옷의 폭·기장을 담는다. 긴 옷→짧은 옷에서는 피부가
필요한 곳까지 천으로 채우며, 스키니에서도 기존의 넓은 옷 윤곽을 따라갈 수 있었다.
마스크만 좁히면 바깥쪽의 옛 옷이 원본 합성 과정에서 되살아난다.

1. **생성 경로 분기:** 상품명에 명시된 스키니·레깅스·슬림핏·머슬핏, 확인된 기장 축소,
   또는 짧은 상품 아래 관절 부위가 원본 옷으로 가려진 경우에 참조 편집 경로를 사용한다.
   기존 신발용 `FLUX.2-klein-4B` 모델을 공유해 원래 옷, 새 옷, 피부, 배경을 함께 재구성한다.
   일반 의류는 기존 CatVTON 경로를 유지한다.
2. **편집 영역:** 기존 옷 전체를 포함하고 주변 배경에 여유를 준다. 이 영역은 신체 치수가
   아니다. 모델에는 기존 옷 윤곽을 실제 체형으로 취급하지 말고, 남는 자리를 배경으로
   복원하도록 지시한다. 얼굴·손·신발·소지품 보호와 최종 원본 복원은 유지한다.
3. **피부색:** 원본의 보이는 피부 내부에서 이상치를 제외한 CIELAB 중앙값을 추정한다.
   생성 결과가 팔·다리 피부로 파싱됐고 원래 옷이 있었던 픽셀에만 색 보정을 적용한다.
   밝기 변화는 제한하고 명암 차이와 질감을 유지한다. 단색으로 채우지 않는다.
   원본 피부 근거가 부족하면 임의의 피부색을 넣지 않고 보정 보류를 알린다.
4. **검사:** 짧은 상품 아래 팔꿈치→손목·무릎→발목 중심 영역이 피부로 복원됐는지 검사한다.
   참조 편집 경로에서는 기장 불일치와 피부 복원 실패를 재시도 대상으로 삼는다.
   기존 최대 재시도 횟수 안에서 더 나은 결과를 고른다.

`FASHION_SHOE_MODEL_PATH`가 설정된 웹에서는 같은 모델 인스턴스를 의류와 신발이 공유한다.
직접 어댑터를 생성하는 코드에서는 `CatVTONTryOn(..., transition_editor=ShoeTryOn(model_path))`로
연결한다. 모델 또는 필수 관절이 없으면 기존 마스크와 경고를 사용한다. 피부색 보정은
가능한 범위에서 수행하지만 이 폴백이 옷 폭·기장 문제를 해결한다고 보장하지 않는다.
`transition_correction=False`로 새 분기와 피부색 보정을 끈 동일 설정 비교가 가능하다.

## GPU 확인

운영 서비스를 변경하지 않고 별도 Slurm 작업으로 실행했다.
CatVTON 25 steps, FLUX 4 steps, seed 42, 비교 실험은 재시도 0회다.
입력 및 평가 코드 SHA-256과 개별 결과는 `transition_2026-09-24.json`에 저장했다.
생성 이미지는 저장소에 커밋하지 않는다.

| 평가군 | 쌍 / 이미지 | 자동 검사 실패: 기존 → 변경 | 하의 기장 실패: 기존 → 변경 |
|---|---:|---:|---:|
| 첫 확인: Simon, Yifeng, 재킷 인물 | 9 / 18 | 4 → 1 | 4 → 1 |
| 추가 확인: 맨투맨, 후드·겹친 하의, 야외 인물 | 9 / 18 | 5 → 1 | 3 → 0 |

두 평가군 모두 생성 오류 0건이다. 첫 평가군에는 새 피부 복원 검사가 아직 없었으므로
실패율을 합쳐 모집단 성공률로 해석하지 않는다. 추가 평가군의 피부 복원 검사 6건은
0.9907~1.0으로 잠정 기준 0.6을 통과했다. 추가 평가군의 얼굴 PSNR 최솟값은
60.91dB, 모델 좌표에서 편집 영역 밖 PSNR은 모두 상한값 99dB였다.

추가 평가군의 변경 경로 생성시간 중앙값은 12.93초(기존 5.24초)였다.
첫 평가군의 최초 FLUX 적재·추론에는 288.15초가 걸렸으므로 콜드 스타트 비용을
제외하고 대기시간을 안내해서는 안 된다.

시각 확인 결과:

- 긴 조거·레깅스·청바지에서 반바지로 바뀔 때 기존 긴 바지 잔류가 줄고 맨다리가 생성됐다.
- 후드·겹쳐 입은 넓은 하의에서 스키니로 바뀔 때 넓은 옷 덩어리가 남지 않고 다리를 따르는
  실루엣이 생성됐다. 가려졌던 실제 치수가 맞다는 검증은 아니다.
- 긴팔·재킷에서 반팔 머슬핏으로 바뀔 때 팔이 드러나고 상품의 짧은 소매가 반영됐다.
- 야외 인물의 스키니 결과는 상품 유사도 검사에 여전히 실패했다(-0.0791, 기준 > -0.03).
  해당 실패는 남겨 두었으며 전체 성공으로 처리하지 않았다.
- 첫 평가군의 Simon 반바지→반바지는 전환 분기가 작동하지 않아 기존 기장 실패가 남았다.
  이번 요청인 긴 옷→짧은 옷과 구분되는 남은 실패다.

초기에 시도한 **CatVTON 마스크 확장만 적용하는 방식은 기각**했다. 확장 배경까지
천 무늬로 채우는 실패가 실제 발생했다. 최종 코드에서는 참조 편집기가 준비되지 않으면
확장 영역을 CatVTON으로 보내지 않으며, 이를 회귀 테스트로 고정했다.

## 한계와 배포 상태

사진에서 가려진 실제 체형·피부색의 정답은 없다. 결과는 원본의 관절·보이는 피부와
상품 사진에 근거한 생성 추정이며, 실제 신체 치수 복원이나 실제 핏 보장이 아니다.
6명·3상품의 편의 표본으로 전체 피부색·자세·복잡한 배경에 대한 일반 성능을 주장하지 않는다.
새 피부 검사 임계값도 아직 잠정값이다. 미니스커트를 반바지로 지시하지 않는 분기에는
단위 테스트가 있지만 이번 GPU 표본에는 미니스커트가 없다.

로컬 웹 연결과 독립 GPU 검증을 완료했다. 운영 릴리스 교체·서비스 재시작·GitHub push는
수행하지 않았다. 실제 서비스에 반영하려면 이 코드와 기존 FLUX 체크포인트 설정을 포함해
별도 배포해야 한다.
