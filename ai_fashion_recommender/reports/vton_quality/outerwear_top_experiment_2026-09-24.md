# 외투 제거 후 상의 착장 실험

공식 외투·이너 정답 마스크와 손·하의 보존 A/B까지 진행한 후속 결과는
[`outerwear_layer_direction_2026-09-25.md`](outerwear_layer_direction_2026-09-25.md)에 있다.

## 목표

퍼·패딩·코트처럼 원래 상체 실루엣이 큰 사진에서 외투를 제거하고, 선택한 상의만
입은 자연스러운 실루엣을 만든다. 포즈 기반 영역은 편집 가이드일 뿐 실제로 가려진
신체 치수의 추정값으로 사용하지 않는다.

## 기존 CatVTON만으로 해결되지 않는 이유

CatVTON의 한 마스크는 기존 옷을 지울 영역과 새 옷을 그릴 영역을 겸한다. 외투 전체를
덮는 넓은 마스크는 새 상의도 외투 폭으로 채우게 만들고, 마스크를 줄이면 퍼 털끝과
소매가 결과 바깥에 남는다. 기존 `outerwear_policy="reassign"`은 힙 아래 오버행을
하의 패스에 넘기지만 좌우 부피를 배경·팔로 복원하지 않는다.

## 구현

`src/outerwear_top_tryon.py`는 다음 영역을 별도로 만든다.

- `erase_mask`: 원래 외투와 경계 여유를 모두 포함하는 실제 편집 영역
- `target_body_mask`: 어깨·골반·팔꿈치·손목으로 만든 좁은 몸통/팔 편집 가이드
- `outer_ring`: `erase_mask` 중 새 상의보다 배경·팔·하의로 복원되어야 할 후보 영역
- `protected_mask`: 얼굴·머리·손·가방·안경·액세서리 등 원본 보존 영역

FLUX.2-klein reference inpainting에는 넓은 `erase_mask`와 실제 상품 이미지를 전달한다.
마스크 밖은 생성 결과를 쓰지 않고 원본 픽셀을 그대로 보존한다. 결과를 다시 FASHN으로
파싱해 외투 바깥 부피에 상의가 남은 비율과 어깨폭 대비 상의 폭을 기록한다.

직접 FLUX 결과와 함께 비교용 `--second-pass-catvton` 변형도 지원한다. 이 변형은 넓은 FLUX
패스가 외투 제거·배경·몸통을 중립 베이스 레이어로 복원하고, 두 번째 CatVTON 패스는
상품 핏에 따라 정한 좁은 `target_body_mask`만 받아 상품 상의를 그린다. 이 전용
CatVTON 인스턴스는 운영 기본 `agnostic` 확장을 쓰지 않고 `upper_mask_policy="native"`로
고정한다. 1차 패스에는 상품 대신 중립 회색 레퍼런스를 전달해 목표 옷을 두 번 그리지
않는다. CatVTON 결과도 좁은 목표 마스크 안쪽만 다시 합성해 블러가 복원된 바깥 링으로
번지지 않게 한다. FLUX 중간 결과도 디버그 폴더에 남겨 어느 단계에서 실루엣이
커졌는지 분리한다.

운영 VTON 라우팅은 아직 바꾸지 않았다. 이 경로는 한 번에 상의 상품 하나만 처리하는
격리 실험이다.

## 실행

GPU 환경에서 저장소의 기존 FLUX.2-klein-4B 체크포인트를 지정한다.

```bash
python ai_fashion_recommender/scripts/eval_outerwear_top.py \
  --person /data/eval/person_in_fur_coat.jpg \
  --top-image /data/eval/reference_top.jpg \
  --model /data/models/FLUX.2-klein-4B \
  --out /data/eval/outerwear_top/fur_01.png
```

같은 입력의 2-pass 변형은 출력 경로만 바꾸어 실행한다.

```bash
python ai_fashion_recommender/scripts/eval_outerwear_top.py \
  --person /data/eval/person_in_fur_coat.jpg \
  --top-image /data/eval/reference_top.jpg \
  --model /data/models/FLUX.2-klein-4B \
  --second-pass-catvton \
  --out /data/eval/outerwear_top/fur_01_two_pass.png
```

단일 패스의 문구 대조에는 `--prompt-variant strict`, 상품 핏 문구 대조에는
`--fit-guidance`를 각각 사용한다. 기본값은 둘 다 비활성이다. 2-pass에는 적용하지 않는다.

출력 이미지 옆에 JSON 리포트가 생기고 `debug/`에는 네 마스크와 오버레이가 저장된다.
앞단이 퍼 외투를 놓친 입력의 마스크만 시험할 때는 `--allow-unconfirmed-outerwear`를
명시한다. 이 모드에서는 외투 판정용 FashionSigLIP도 불러오지 않아 사용자가 외투임을
확인한 입력의 격리 실험만 실행한다. 이 옵션을 운영 기본값으로 사용하지 않는다.

클러스터에서는 먼저 격리 체크아웃을
`/data1/dsl01/eval/outerwear_top_20260924/repo`에 준비하고 평가 디렉터리를 만든 뒤,
다음처럼 입력만 환경변수로 지정해 제출한다. GPU 실험 결과에 따라 기본값은 단일 FLUX
패스다. 2-pass 비교가 필요할 때만 `OUTERWEAR_TOP_TWO_PASS=1`을 추가한다.

```bash
mkdir -p /data1/dsl01/eval/outerwear_top_20260924
sbatch --export=ALL,\
OUTERWEAR_TOP_PERSON=/data1/dsl01/eval/input/person_in_coat.jpg,\
OUTERWEAR_TOP_REFERENCE=/data1/dsl01/eval/input/reference_top.jpg \
  gpu_server/jobs/outerwear_top_eval.sbatch
```

## 1차 평가 세트

같은 사람의 외투 착용/미착용 사진 쌍이 가장 좋다. 자세와 배경을 최대한 맞추고 다음을
각 5명 이상 포함한다.

- 퍼·무스탕
- 패딩
- 롱코트
- 짧은 재킷·가디건

상품 상의는 레귤러핏·슬림핏·오버핏을 나눠 같은 사람과 교차한다. 보이지 않던 실제 몸과
하의를 복원했다고 주장하지 않으며, 미착용 사진은 실루엣 오차를 재는 비교 기준으로만 쓴다.

## 채택 전 확인 항목

- `outside_mask_preserved == true`
- 외투 털끝·칼라·소매가 결과에 남지 않음
- 얼굴·머리·손·하의·배경에 눈에 띄는 변형이 없음
- FASHN 폭과 바깥 링 수치는 육안 판정을 보조하며 단독 합격 기준으로 쓰지 않음
- 레귤러/슬림 상품이 외투 폭으로 생성되지 않음
- 상품의 색·종류·소매·기장·주요 디테일 유지
- 팔 추가, 팔 절단, 허리 뒤틀림, 배경 반복 같은 생성 결함 없음

`outer_ring_top_fraction`은 긴소매도 외투 바깥 링 점유로 세는 한계가 있다. 따라서 0.25를
넘더라도 결과 상의 폭이 목표 폭의 110% 이하이면 경고하지 않는다. 흰 상의와 흰 배경처럼
파서가 경계를 놓치는 경우도 있으므로 이 수치는 성공 판정이 아니라 검토 우선순위로 쓴다.

## 2026-09-25 GPU 실험 결과

운영 서비스와 기존 평가 폴더는 건드리지 않고 `hpc-stat1`의 격리 경로
`/mnt/data1/dsl01/eval/outerwear_top_20260924`에서 실행했다.

| 입력 / 방식 | 시간 | 원본 폭 | 결과 폭 | 목표 폭 | 바깥 링 상의 | 육안 판정 |
|---|---:|---:|---:|---:|---:|---|
| 데님 재킷 + 검정 레이어드 폴로 / 단일 FLUX | 20.15초 | 1.5634 | 1.4208 | 1.4552 | 0.33143 | 채택 후보 |
| 같은 입력 / FLUX + CatVTON 2-pass | 72.97초 | 1.5634 | 1.3421 | 1.4552 | 0.14317 | 기각 |
| 퍼 재킷 + 흰 반소매 블라우스 / 단일 FLUX | 20.39초 | 1.7957 | 0.6969* | 1.5163 | 0.02610 | 재검토 후 기각 |

모든 완료 결과에서 `outside_mask_preserved == true`였고 편집 영역 내부 변경률은
0.91 이상이었다. 데님 입력의 단일 FLUX 결과는 재킷을 제거하면서 상품의 검정색, 칼라,
그래픽, 레이어드 긴소매를 유지했다. 당시 상품은 실제 슬림핏인데 실행 입력을 레귤러핏으로
지정했다. 슬림핏으로 수정해 재실행해도 결과 픽셀은 완전히 동일했다. 직접 FLUX에서는
핏 메타데이터가 생성 문구에 전달되지 않았고, 목표 마스크가 기존 외투 마스크 안에 있으면
입력 마스크도 변하지 않기 때문이다. 따라서 처음 제시한 목표 폭과의 2.4% 차이는 핏
정확도의 근거가 아니다. 바깥 링 수치가 높은 것은 정상적인 긴소매가 링에 들어간 영향이다.

퍼 입력에서는 털 외투와 넓은 어깨 실루엣이 사라지고 흰 반소매 상의, 노출된 팔, 좁아진
허리선이 생성됐다. 다만 후속 검토에서 원래 주머니에 있던 손이 남은 상태로 새 팔과 손이
하나 더 그려진 것을 확인했다. 이 사례의 초기 채택 후보 판정은 취소한다. `0.6969`로 표시한
결과 폭은 흰 상의가 흰 배경과 맞닿아 FASHN 파서가 옷 경계를 누락한 값이므로 실제 폭으로
해석할 수 없다. 외투에 가려졌던 팔과 몸통은 정답 복원이 아니라 모델이 새로 생성한 영역이다.

2-pass 결과는 수치상 폭이 줄었지만 중립 베이스 상의가 어깨와 옆구리에 남고 상품 상의가
잘린 형태로 겹쳤다. 단일 패스보다 3.6배 느리면서 육안 품질도 낮아 기본 경로에서 제외했다.
긴 코트 입력 한 건은 손목 포즈 신뢰도가 부족해 결과를 만들지 않고 종료됐다. 이는 넓은
마스크로 임의 생성하는 것보다 안전한 현재의 fail-closed 동작이다.

처음 두 사람의 결과만 놓고는 단일 FLUX가 가능성 있는 후보로 보였지만, 퍼 사례의 손 중복을
재검토에서 발견했다. 이후 추가 평가에서도 긴 외투와 이너가 드러나는 재킷에서 실패가 많아
적용 범위를 좁혀야 했다.

### 원인별 통제 실험

마스크·상품·시드·설정을 고정하고 제거 지시 문구만 강하게 만든 `strict` 3건을 실행했다.

- `short_02446_regular`: 원래 회색 이너 밑단이 사라져 개선됐다. 목 부근의 작은 이너
  흔적은 남아 있어 최종 통과로 보지 않는다.
- `puffer_05412_relaxed`: 흰 털 윤곽과 지퍼가 그대로 남아 개선되지 않았다.
- `longcoat_00475_relaxed`: 원래 배경·팔 주변이 더 어색해지고 팔이 하나 추가돼 악화됐다.

핏 메타데이터를 직접 생성 문구에 넣는 `--fit-guidance`도 같은 데님 사진·상품에서
슬림/레귤러로 비교했다. 두 이미지는 13.7%의 픽셀이 다르지만 파서가 측정한 상의 폭은
각각 1.4306과 1.4355로 거의 같고, 육안의 몸통 폭도 구분하기 어렵다. 이 옵션만으로는
핏을 안정적으로 제어한다고 볼 수 없어 기본값으로 켜지 않았다.

현재 우선순위는 외투 경계 바깥의 끈·털·긴 자락을 포함하는 마스크와, 외투 뒤의 기존
이너를 새 상의와 구분하는 레이어 분리다. 짧은 재킷의 일부는 현 방식으로 후보가 되지만,
롱코트·패딩을 운영 자동 경로에 넣을 근거는 아직 없다. 같은 사람의 외투 미착용 사진 쌍이
없어서 실제 신체 실루엣 오차는 측정하지 못했다.

## 2026-09-25 개선 실험: 스튜디오 배경 복원과 손 중복 경고

선택 옵션 `--restore-studio-background`를 추가했다. 원본에서 마스크 밖 좌우의 배경색을
행별로 측정하고, 생성 결과에서 배경으로 분류된 편집 픽셀을 좌우 조명 기울기에 맞춰
복원한다. 배경이 불균일하거나 결과 상의의 파서 인식률이 0.50 미만이면 적용하지 않는다.
원본 마스크 바깥과 보호 영역은 수정하지 않는다. 이는 흰 스튜디오 배경용 후처리이지
외투/이너 분할 모델이 아니다. 흰 상품과 배경의 경계가 애매한 경우에는 여전히 오판할 수
있어 기본값은 꺼져 있다. 클러스터 배치 실험에서는
`OUTERWEAR_TOP_RESTORE_STUDIO=1`로 켠다.

같은 인물·상품·시드로 GPU 생성 경로를 재실행한 결과는 다음과 같다. 새 결과는 격리
디렉터리의 `output/*_studio_integrated.png`와 동명 JSON에 저장했다.

저장된 생성 결과를 후처리만 한 추가 대조에서 롱코트 `01582`는 2.434%를 복원했지만

되지만 핵심 과제인 외투·이너 분리와 가려진 팔 재구성은 해결하지 못한다.

퍼 사례를 재검토하며 FASHN 손 영역의 큰 연결 성분이 원본 2개에서 결과 3개로 늘어난

추가하고 경고를 표시한다. 이 수치는 손/피부 파서의 오차가 있을 수 있어 자동 합격·기각
판정으로 사용하지 않는다. 패딩 `05412`의 작은 오검출 성분은 면적 기준에서 제외된다.

손 중복 경고가 출력되는 것을 확인했다.

다음 품질 개선에는 실제 외투 픽셀과 이너 픽셀을 따로 표시한 소량의 검증 데이터,
동일 인물의 외투 착용/미착용 사진 쌍, 가려진 손·팔의 연결성 검사가 필요하다. 현재
FASHN의 `top` 클래스 하나만으로는 코트 끈·털·이너·머리 아래 코트 조각을 분리할 수 없다.
