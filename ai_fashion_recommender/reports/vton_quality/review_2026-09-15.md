인수인계 문서의 수치와 실제 코드를 교차 검토했다. **기장·경고 판정과 평가 코드의
오류를 수정했지만, 생성 이미지의 핏 품질이 개선됐다고 판정하지는 않았다.**
기존 생성 결과의 재집계, 로컬 회귀 검증, **실제 사진 12명·하의 상품 24개의 게이트

## 후속 보완: 발목 미관측의 일괄 보류 완화

사용자 피드백 후 기존 검사 보류 96조합(4명×24상품)의 원본 분할 마스크를 다시 확인했다.
`2-model_4`는 치마 밑단이 y=988에서 끝나고 화면 높이는 1024였다. 양쪽 무릎도
화면 안에 관측된다. 발목이 안 보인다는 이유만으로 이 사진까지 보류한 것은 과도했다.

발목이 없더라도 **양쪽 골반·무릎이 신뢰도 기준을 충족하고, 옷 밑단이 프레임
하단에서 잘리지 않고 보이는 경우** 무릎 위/무릎 부근 기장을 판정하도록 보완했다.
장기장(7부·앵클·풀렝스)을 이 경로로 추정하지 않으며, 학습 헤드가 관측값을
덮어쓰지 못하도록 유지한다. 기준은 초기 기하 휴리스틱이며 광범위한 보정은 남아 있다.

실제 마스크에서 `2-model_4`가 **분석 불가→무릎 기장**으로 바뀐다.
나머지 세 사진은 원래 바지 라벨이 영상 마지막 행까지 각각 241/219/198픽셀
이어져 실제 밑단이 보이지 않는다. 이 세 사람은 보류를 유지한다.
따라서 보류 범위는 **96→72조합**으로 줄어든다. 이는 착장 전체 분석 불가가 아니라
현재 옷과 상품 사이의 **기장 차이 검사만** 보류한다는 뜻이다.

아래의 96조합과 작업 222005 결과는 일괄 발목 기준을 사용했던 이전 감사 기록이다.
최신 검증은 작업 222026과 최신 `gate_audit.json`을 기준으로 한다.
작업 222026은 39초 만에 `COMPLETED (0:0)`로 종료됐다. 실제 192조합에서
**검사 가능 120, 보류 72, 큰 기장 차이 경고 6**을 확인했다.
최신 전체 테스트는 **389 passed, 2 failed, 651 subtests passed**이며 실패는 기존 두 건이다.

## 1. 기존 평가에서 추가로 발견한 문제

### 사람 단위 부트스트랩의 중복 추출 가중치 소실 — 수정

`analyze_vton_fit.py`는 사람을 복원추출한 다음 원래 `person` 값을 유지했다.
`within()`과 `gap()`이 다시 사람별로 묶으면서 중복 추출된 사람을 한 사람으로 합쳤다.
따라서 사람별 통계량 평균의 신뢰구간이 올바른 클러스터 부트스트랩이 아니었다.
행 전체의 평균·상관처럼 다시 묶지 않는 통계량에는 이 문제가 없다.

각 추출 클러스터에 별도 ID를 부여하도록 고쳤다. 원본 행은 수정하지 않는다.
사람별 값 0, 9, 30에서 첫 사람을 두 번, 둘째를 한 번 뽑으면 평균은 3이다.
HEAD의 원본 함수를 직접 실행하면 4.5, 수정본은 3.0이다. 회귀 테스트로 고정했다.

기존 480쌍 및 wide 192쌍의 JSON을 다운로드해 재계산했다. 반바지 3개를
판매자 상품명·카테고리로 제외한 하의 168쌍, 8명의 결과는 다음과 같다.

| 같은 사람 안의 와이드−나머지 폭 차이 | 기존 보고서 95% CI | 수정한 95% CI |
|---|---|---|
| native: +0.009 | [−0.025, +0.047] | **[−0.044, +0.051]** |
| 전부 넓힘: +0.093 | [+0.049, +0.133] | **[+0.044, +0.147]** |

중심값과 큰 방향은 유지되지만 기존 신뢰구간은 교체해야 한다.
수정 결과도 이 8명과 고정 상품 집합에 조건부인 구간이며 실사용자 일반화를 보장하지 않는다.

### 변종마다 PSNR 측정 영역이 다름 — 측정 경로 보강

wide 실험은 넓어진 마스크 밖에서 PSNR을 계산했다. native에서 검사하던 픽셀이
wide에서는 검사에서 제외된다. 따라서 둘의 `outside_psnr`을 그대로 비교해
“보존 성능이 떨어지지 않았다”고 결론 내릴 수 없다.

새 평가에는 모든 변종을 **동일한 native 마스크 밖**에서 측정한
`native_outside_psnr`/`native_outside_ssim`을 추가했다. 확장으로 의도적으로 바뀐
부분도 포함되므로 기존 기준과의 손상·변경량을 보여준다. 변경 마스크 밖의 기존
지표도 유지한다. `audit_vton_gates.py`는 기존 이미지로 동일 영역을 재측정하도록
실행했다. 168개 긴바지 쌍에서 native 기준 마스크 밖 PSNR 중앙값은
**47.59→37.89dB**, 실제 넓힌 104쌍만 보면 **47.59→33.95dB**였다.
의도한 확장 영역도 포함되므로 이 감소를 전부 시각적 손상으로 해석할 수는 없지만,
기존 영역까지 그대로 보존했다는 합격 조건은 충족하지 않는다.

### 학습 모델 기장값을 평가의 반바지 정답으로 사용 — 수정

집계에서 모델 추정 `catalog_length == 반바지`로 평가 제외 대상을 정했다.
이제 판매자 상품명과 `detail_category`를 사용하며 Shorts, Hot Pants, Half Tights,
숏팬츠 등을 포함한다. 새 표본 추출에도 적용했다.

단, 추출 규칙을 수정하면 같은 난수 시드여도 상품이 달라진다.
`--selection-refs <기존 refs.json>`으로 기존 상품과 순서를 고정할 수 있도록 했다.
기존 평가와 A/B 비교할 때는 반드시 이 옵션을 사용하고 출력 폴더를 분리한다.
추가로 결과별 manifest에 입력 사진·상품·체크포인트·소스 SHA-256과 시드·설정을
기록한다. 코드나 입력이 달라졌거나 manifest가 없는 기존 JSONL에는 이어 쓰지 않는다.
속성 헤드나 FASHN 파서가 로드되지 않으면 fallback 결과를 평가하지 않고 중단한다.

## 2. 선택적 하의 마스크 후보 — 현 기준으로 기각

기존 native/wide 쌍에서 상품명에 와이드·벌룬·배기·커브드 또는 영문 동등 표현이
있는 긴바지만 wide 결과를 선택했다. 반바지는 제외했다. **새로 합성한 결과가 아니라
기존 결과를 조합한 정책 사후 분석**이며 별도의 일반화 검증이 아니다.

| 지표 | 결과 |
|---|---|
| 매칭된 긴바지 쌍 | 168쌍, 8명, 누락 0 |
| 같은 사람 안 와이드−나머지 폭 차이 | +0.269 [0.147, 0.392] |
| 슬림·레귤러 판매자 태그 상품의 폭 증가 | **+0.046 [0.020, 0.074]** |
| 슬림·레귤러 태그인데 마스크가 넓어진 쌍 | 16쌍 |
| 레퍼런스 top-1 | 38.7% → 45.8% |
| top-1 차이 | +7.1%p [1.8, 11.3] |
| 동일 native 영역 PSNR 중앙값 | 47.59 → 37.89dB |

인수인계의 “슬림·레귤러 태그 결과 폭이 늘지 않을 것” 조건을 충족하지 않는다.
판매자의 전체 핏 태그와 바지통 형태는 다른 속성이라 서로 충돌하는 상품이 있다.
따라서 keyword 선택을 운영에 승격하지 않았다. 판매자 태그를 사후에 추가해
통과하도록 맞추는 대신, 실제 바지통 목표와 전체 핏의 평가 정의를 먼저 구분해야 한다.

`eval_vton_fit.py --mask-mode selective-wide`는 별도 실험 옵션으로만 추가했다.
상·하의 전체 쌍을 유지하며 상의는 기존 마스크를 사용한다. smoke 결과 파일도
변종별로 분리해 다른 변종의 완료 기록 때문에 실험이 건너뛰어지는 문제를 고쳤다.

## 3. 품질 게이트 수정

- **현재 기장:** 골반·발목의 가시도 0.5 이상, 유한 좌표, 화면 안 위치를 모두 확인한다.
  관측 불가면 기장을 계산하지 않는다. `OutfitAnalyzer`의 후속 학습 헤드가
  이를 덮어쓰지 못하게 하고, 사용자 요약의 `pant_length`도 보류한다.
  임계값 0.5는 보수적 초기 기준이며 실제 라벨 데이터로 보정한 값은 아니다.
- **레퍼런스 기장:** 정제 이미지 대신 원본 상품 사진을 판정에 전달한다.
  명시적인 반바지 상품명은 먼저 사용한다. category의 팬츠 판정과
  lower_length의 쇼츠 판정이 충돌하면 긴바지로 단정하지 않고 보류한다.
- **검사 보류:** 기장 비교 불가를 경고 없는 통과로 처리하지 않고
  “기장 비교를 보류했다”는 안내를 남긴다. 품질 실패 판정과는 구분된다.
- **아우터 soft 경고:** 베스트 분류에 대해 단일 상의이고 실제 보이는 소매가
  민소매인 경우만 생략한다. 레이어드·판단 보류, 코트 및 다른 아우터 경고는 유지한다.
  민소매라는 이유만으로 실제 겹쳐 입은 베스트까지 제외하지 않는다.

발목 가시도 0.03의 합성 입력은 원본 코드에서 “무릎 기장 바지”, 수정본에서
“분석 불가”가 된다. 0.99 확신의 풀렝스 헤드가 들어와도 최종 기장을 보류하는
통합 회귀 테스트가 통과했다.

### 실제 사진 재평가 결과

- model_5/model_7 모두 **베스트·단일 상의·민소매**로 분류됐다. 두 사람에서
  기존 경고가 1→0이고 다른 10명에서 아우터 경고 변화는 없었다. 이 경고는
  원래 착장에만 의존하므로 기존 24상품씩 **48개 조합의 오경고가 해소**된다.
- MS5945210/MS5308542가 실제 헤드 판정에서 **쇼츠→롱·긴바지 기장**으로 바뀌었다.
  기존 반바지 3개의 쇼츠 판정은 유지된다.
- 하의 대상 8명 중 발목이 잘린 4명의 기장은 분석 불가로 바뀌었다.
  기존 하의 192조합을 재계산하면 기장 차이 경고는 **15→6**, 검사 보류는
  **0→96**이다. 남은 6건은 기존 검토에서 확인된 긴바지 2명×반바지 3개다.
  새 사람 라벨링으로 민감도/특이도를 추정한 결과는 아니며, 검사 보류는 통과가 아니다.

### Simon_1의 원인과 수정

실제 segmentation에서 반바지 본체는 33,697픽셀이고 y=650~811인데,
신발 윗부분 **969픽셀**이 바지 라벨로 분리되어 y=1051~1082에 있었다.
이 조각이 바지 픽셀의 2%를 넘어 98백분위 밑단을 발목으로 끌어내렸다.

기장 측정에만 최대 성분 면적의 5%보다 작은 분리 성분을 제외했다.
양쪽 다리가 떨어진 긴바지는 둘 다 남기는 회귀 테스트를 추가했고,
파싱/VTON 마스크 자체는 변경하지 않았다. 실제 결과는 **긴바지→반바지**다.
5%는 해당 오라벨과 합성 회귀 사례를 바탕으로 잡은 초기 기준이며 보편적인 최적값은 아니다.

또한 `pant_length` 헤드의 클래스가 **7부·앵클·풀렝스 세 개뿐**인데 쇼츠에도
적용되고 있었다. 반바지·치마에는 이 헤드를 적용하지 않고 일반 기장 헤드로
돌리도록 수정했다. Simon_1의 사용자 요약용 기장은 **크롭·앵클→해당 없음**으로
바뀌며, 요약은 올바른 `bottom_length=반바지`를 사용한다.
