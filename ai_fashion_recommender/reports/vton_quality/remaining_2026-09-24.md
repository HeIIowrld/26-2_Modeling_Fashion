# 생성 경로 잔여 결함 수정 및 GPU 재검증

## 수정한 결함

1. **반바지 → 반바지에서 긴바지가 생성됨.** 더 짧아지는 경우에만 보정하던 분기를
   수정했다. 짧은 목표 기장이면 현재 기장과 무관하게 기존 참조 편집기로 보낸다.
   편집기·관절 정보가 없으면 기존 경로와 한계 경고를 유지하며 확장 배경 마스크는
   CatVTON에 전달하지 않는다.
2. **피부 검사가 원래 맨살을 제외함.** 검사할 팔·다리 중심선에서 원래 옷뿐 아니라
   원래 피부도 포함한다. 편집 영역 밖·배경·손·신발은 제외한다.
3. **양쪽 평균이 한쪽 실패를 가림.** 충분한 픽셀이 있는 팔·다리를 따로 측정하고
   최솟값으로 판정한다. 종전 평균 0.743으로 통과하던 한쪽 다리 실패를 테스트로 재현했다.
4. **현재 착장 분석이 없으면 상품명 기장까지 버림.** 원본 분석 유무와 독립적으로
   목표 기장을 추출한다. 상품명에 명시된 반팔·쇼츠로 회귀 테스트했다.
5. 상품 유사도 경고를 실제 계산에 맞게 정정했다. 값은
   `결과-상품 유사도 − 원본-상품 유사도`이며 결과가 원래 옷과 더 닮았다는 직접
   증거가 아니다. 수식·임계값·재생성 여부는 바꾸지 않았다.

## 검증

새 회귀 테스트는 수정 전 5개가 실패했고 수정 후 모두 통과했다.
전환·마스크·품질 관련 106개 및 22 subtests, 가상 피팅·웹 스모크 21개 및
7 subtests가 통과했다. Python 컴파일과 `git diff --check`도 통과했다.

독립 GPU 작업 239738은 3분 51초에 exit 0으로 종료했다.
3명 × 3상품 × 2경로 = 최종 결과 18개, 실제 생성 시도 24회, 실행 오류 0건이다.
평가 스크립트에 `--max-retries 1`을 추가해 운영 기본값과 같은 조건부 재생성까지
검증했다. 입력·코드 SHA256은 `remaining_2026-09-24.json`에 기록했다.

| 항목 | 기존 CatVTON 경로 | 수정 경로 |
|---|---:|---:|
| 결과 수 | 9 | 9 |
| 자동 검사 실패 결과 | 4 | 1 |
| 하의 기장 검사 실패 | 3 | 0 |
| 총 생성 시도 | 14 | 10 |
| 결과당 소요시간 중앙값 | 9.34초 | 10.12초 |
| 얼굴 PSNR 최솟값 | 61.51dB | 60.91dB |

수정 경로의 피부 검사 6건은 0.9835~1.0으로 모두 통과했다. 편집 영역 밖 PSNR은
양쪽 모두 상한값 99dB였다. 9개 비교 시트를 직접 확인했으며 Simon의 기존
반바지 → 반바지 실패는 맨다리가 보이는 짧은 옷으로 바뀌었다. 긴바지 → 반바지,
긴팔 → 반팔, 스키니 전환에서도 기존 긴 옷 잔류를 줄이는 결과를 확인했다.

시간은 서버 캐시와 재시도 횟수의 영향을 받으므로 일반 서비스 지연 보장이 아니다.
이전 평가와 재시도 조건도 달라 실패율을 합산하지 않는다.

## 남은 한계

야외 사진의 검정 스키니는 두 번 생성해도 상품 유사도 변화량 -0.0791로
기준(-0.03 초과)을 통과하지 못했다. 실제 정제 상품 이미지를 확인했으며 정상적으로
검정 스키니가 입력됐다. 시각적으로 검정색·긴 기장·밀착 실루엣은 반영됐지만,
이 검사만으로 디테일 불일치와 임베딩의 오탐을 구분할 수 없다. 실패를 그대로 기록했다.
한 사례에 맞춰 기준을 완화하지 않았다. 추가 상품·정답 평가를 통한 지표 검증이 필요하다.

쇼츠의 밀착 정도 등 세부 핏까지 동일하다는 보장은 없다. 가려진 실제 체형의 정답도
없으며 이번 표본은 일반 성능을 보장하지 않는다. 운영 배포·서비스 재시작·GitHub push는
수행하지 않았다. 이미지는 로컬 `tmp/transition_review/remaining`과 서버
`eval/tryon_transition_20260924/out_remaining`에만 보관했다.

GPU 실행 후 변경은 상품 유사도 경고 문구·설명뿐이며 생성 로직과 판정 기준은 같다.
