# 하의 핏 4종 부트스트랩 학습 기준

이 문서는 첫 GPU 파인튜닝에서 사용하는 `슬림 / 스트레이트 / 세미와이드 / 와이드`의 경계를 고정한다. 자동 선별 라벨은 연구용 약지도이며, 서비스 체크포인트로 승격하기 전에 사람이 검수한다.

| 클래스 | 실루엣 판정 기준 | 다른 클래스와의 경계 | 자동 선별 기준 |
|---|---|---|---|
| 슬림 | 허벅지부터 종아리까지 몸선을 비교적 가깝게 따르고 밑단 폭이 좁다. 이번 실험에서는 스키니와 테이퍼드를 슬림에 포함한다. | 스트레이트보다 무릎과 밑단이 분명히 좁다. | FashionSigLIP 슬림 점수, 하위 폭 기하의 좁은 구간, Fashion200K `skinny / tapered` 메타데이터 후보가 함께 맞는 표본을 우선한다. |
| 스트레이트 | 허벅지 아래에서 밑단까지 폭 변화가 작고 다리선이 거의 수직이다. | 슬림보다 여유가 있지만 세미와이드처럼 전체 통이 넓지는 않다. | Fashion200K `straight-leg` 명시 표본을 우선하고, FashionSigLIP 모순 점수와 바지 마스크 폭을 함께 검사한다. |
| 세미와이드 | 골반·허벅지에 여유가 있고 밑단까지 중간 정도의 넓은 통을 유지한다. | 스트레이트보다 확실히 넓고 와이드보다 부피가 작아야 한다. | 직접 메타데이터 정답이 없으므로 FashionSigLIP 세미와이드 예측과 도메인 내 마스크 폭 중간 구간이 동시에 맞는 표본만 쓴다. |
| 와이드 | 허벅지부터 밑단까지 넓고 느슨하며 양쪽 바짓단의 가로 폭이 크다. 팔라초를 포함한다. | 세미와이드보다 전체 통과 밑단 폭이 뚜렷하게 크다. | Fashion200K `wide-leg / palazzo` 명시 표본을 우선하고, FashionSigLIP 및 넓은 마스크 기하가 반대하지 않는지 검사한다. |

## 데이터와 분할

| 항목 | 기준 |
|---|---|
| 목표 수량 | 클래스당 200장, 총 800장 |
| 도메인 균형 | 각 클래스마다 사용자형 착장 100장 + 쇼핑 착용 사진 100장 |
| 데이터 출처 | 사용자형: DeepFashion-MultiModal, 쇼핑형: Fashion200K |
| 이미지 조건 | 사람이 실제로 착용한 사진, 하의가 충분히 보이고 마스크가 이미지 하단까지 이어지는 사진 |
| 제외 조건 | 평면 상품 사진, 하의가 심하게 가려짐, 측면·교차 자세로 폭 판정이 어려움, 잘림, 마스크 면적 부족 |
| 분할 | 동일 의상/상품 `group_id`가 split을 넘지 않도록 클래스·도메인별 70% train / 15% validation / 15% test |
| 라벨 상태 | 모든 자동 선별 행은 `pending_human_review`; 사람 검수 전 배포 금지 |

## 학습 및 판정

FashionSigLIP은 고정하고 분류 헤드만 학습한다. 동일한 데이터와 분할에서 `rgb_only`, `masked_only`, `rgb_mask`, `rgb_geometry`, `rgb_mask_geometry` 다섯 구성을 비교한다. 주 지표는 네 클래스에 대한 test active macro-F1이며, 클래스별 F1과 `user/shop` 도메인별 점수도 함께 기록한다. `rgb_mask_geometry`가 `rgb_only`보다 실제로 좋아질 때만 최종 후보로 채택한다.

자동 라벨은 모델 입력과 연관된 약지도이므로 결과 점수가 실제 사람 라벨 성능을 뜻하지 않는다. 최종 평가는 별도의 사람 검수 test set으로 다시 수행한다.
