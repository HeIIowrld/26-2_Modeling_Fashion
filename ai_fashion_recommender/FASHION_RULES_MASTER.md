# 한국형 AI 코디 추천 통합 패션 규칙

조사일: 2026-08-13

> 기존 패션 규칙 문서와 팀원 3명의 제안을 통합한 마스터 문서다. 코디에 하나의 정답을 정하는 것이 아니라 사용자의 목적, 취향, 날씨와 보유 옷을 고려해 실패 가능성이 낮은 후보를 먼저 찾기 위한 기준으로 사용한다.

## 문서 사용 원칙

- 사용자의 명시적인 요구와 드레스코드를 일반 규칙보다 우선한다.
- 체형을 미적 우열이나 결점으로 평가하지 않는다.
- `잘 입음`은 한 가지 점수가 아니라 목적 적합성, 착용 가능성, 실루엣, 색상, 소재와 취향의 조합으로 판단한다.
- 사진에서 불확실하게 추정한 정보보다 상품 상세정보와 사용자 입력을 우선한다.
- 미니멀, 스트리트, 맥시멀처럼 스타일 의도가 뚜렷하면 관련 감점을 완화한다.
- 유행 규칙과 장기적으로 유지되는 조형 원칙을 분리한다.
- 모든 점수에는 적용한 규칙과 추천 이유를 함께 제공한다.

## 근거 수준

- **A**: 국내 공공 데이터 또는 국내 등재 학술연구
- **B**: 패션 전공자·스타일리스트 등 국내 전문가 자료에서 반복 확인된 내용
- **C**: 해외 패션 매체·스타일링 서비스의 실무 가이드
- **D**: 팀 프로젝트 가설로 전문가 검수와 사용자 실험이 필요한 내용

# 1. 입력 데이터와 아이템 태깅

모든 규칙은 먼저 각 옷을 같은 형식으로 태깅한 뒤 적용한다.

| 구분 | 필수 속성 |
|---|---|
| 기본 정보 | 아이템 ID, 상품명, 가격, 재고, 구매 링크 |
| 카테고리 | 상의, 하의, 원피스, 아우터, 신발, 가방, 액세서리 |
| 세부 카테고리 | 셔츠, 니트, 후드, 슬랙스, 데님, 카고, 로퍼 등 |
| 색상 | 대표색, CIELAB 또는 CIELCh 값, 명도, 채도, 색 면적, 주색·보조색·포인트색 |
| 실루엣 | 슬림·레귤러·오버, 크롭·기본·롱, 허리선, 상·하의 부피감 |
| 디자인 | 넥라인, 칼라, 소매, 절개선, 포켓, 장식과 포인트 위치 |
| 패턴 | 종류, 크기, 반복 간격, 대비, 차지하는 면적 |
| 소재 | 소재명, 두께, 표면 질감, 광택, 통기성, 보온성 |
| 맥락 | 격식도, 계절, 활동성, 스타일 태그, 사용 목적 |
| 신뢰도 | 상품 정보 기반인지, 이미지 추정인지, 추정 확률이 얼마인지 |

필수 슬롯은 상황에 맞게 정의한다. 일반적인 상·하의 코디는 `상의 + 하의 + 신발`, 원피스 코디는 `원피스 + 신발`을 기본 슬롯으로 둔다. 아우터, 이너, 가방, 양말, 모자와 액세서리는 선택 슬롯이다.

### 태깅 예시

- 그레이진: `하의 / 데님 / 레귤러 / 캐주얼 / 사계절`
- 울 슬랙스: `하의 / 울 / 스트레이트 / 포멀 / 가을·겨울`
- 코튼 카고팬츠: `하의 / 면 / 와이드 / 캐주얼 / 봄·가을`

색만 같은 회색 바지라도 카테고리, 소재, 핏과 격식도가 다르므로 서로 다른 상품으로 평가한다.

# 2. 평가 순서

1. 사진과 분석 결과의 신뢰도를 확인한다.
2. 재고, 예산, 사용자가 제외한 요소를 확인한다.
3. 목적, 드레스코드, 날씨와 활동성에 맞지 않는 후보를 제외한다.
4. 필수 슬롯과 사이즈·착용 가능성을 확인한다.
5. 원하는 실루엣과 상·하의 비율을 평가한다.
6. 색상, 패턴, 소재와 포인트의 조화를 평가한다.
7. 신발과 액세서리가 전체 코디를 연결하는지 평가한다.
8. 보유 옷과의 활용도, 사용자 취향과 유행 선호를 반영한다.
9. 점수와 함께 추천 이유와 불확실성을 제공한다.

다음 조건은 점수 감점이 아니라 우선 제외 조건으로 사용한다.

- 재고 없음 또는 예산 초과
- 사용자가 명시적으로 제외한 색상·소재·카테고리
- 필수 드레스코드 위반
- 심한 날씨 부적합 또는 활동을 방해하는 신발·의류
- 사이즈 정보상 착용이 어렵다고 판단되는 상품

# 3. 데이터 신뢰도 규칙

## R-DAT-01 불확실한 이미지 분석 결과를 확정값처럼 사용하지 않는다

- 신뢰도: **높음**
- 근거 수준: **A + D**
- 조건: 사진에서 색상, 소재, 핏, 체형 또는 의류 속성을 추정하는 경우
- 규칙:
  - 배경, 피부, 머리카락과 그림자를 제거한 의류 마스크 안에서만 특징을 계산한다.
  - 상품 상세정보가 있다면 이미지에서 추정한 소재·사이즈보다 우선한다.
  - 모델 신뢰도가 낮으면 해당 항목을 강하게 감점하지 않고 중립 점수에 가깝게 보정한다.
  - 필수 정보가 없으면 `판단 불가`로 표시하거나 사용자에게 추가 입력을 요청한다.
- 금지:
  - 한 장의 사진만으로 실제 신체 치수를 cm 단위로 단정
  - 낮은 확률의 의류 분류를 추천 사유에 확정적으로 표현

불확실성 보정은 다음처럼 사용할 수 있다.

`적용 점수 = 50 + 분석 신뢰도 × (원점수 - 50)`

신뢰도가 낮을수록 0점이 아니라 중립값인 50점에 가까워지므로 잘못된 분석으로 후보가 과도하게 탈락하는 것을 줄일 수 있다.

# 4. 목적·격식도·카테고리 규칙

## R-CTX-01 목적과 복장 수준을 미적 점수보다 먼저 확인한다

- 신뢰도: **높음**
- 근거 수준: **A + B**
- 조건: 출근, 면접, 결혼식, 데이트, 여행 등 목적이 입력된 경우
- 규칙:
  - 목적별 격식 범위, 활동량, 노출 허용 범위와 신발 기능을 먼저 확인한다.
  - 같은 출근이라도 자유 복장, 비즈니스 캐주얼, 포멀 등 조직 규정을 추가로 반영한다.
  - 사용자나 장소가 명시한 드레스코드를 일반 규칙보다 우선한다.
- 주의: 목적만으로 특정 아이템을 무조건 금지하지 않는다.

## R-CTX-02 아이템의 격식도와 목적의 격식도를 함께 비교한다

- 신뢰도: **중간**
- 근거 수준: **B + D**
- 규칙:
  - 각 아이템의 격식도를 내부적으로 1~5 범위로 태깅한다.
  - 카테고리뿐 아니라 소재, 형태, 색상과 디테일을 함께 본다.
  - 코디의 평균 격식도가 목적 범위에 가까울수록 가점한다.
  - 아이템 사이의 격식도 차이가 지나치게 크면 감점한다.
- 예외:
  - 슬랙스와 미니멀 스니커즈처럼 의도된 믹스는 허용한다.
  - 스트리트, 믹스매치 스타일을 선택하면 아이템 간 격식도 차이 감점을 줄인다.
- 주의: `울 슬랙스=4` 같은 초기값은 가설이며 전문가 검수와 사용자 데이터로 보정한다.

## R-CTX-03 상의와 하의의 상황 적합도를 각각 계산한다

- 신뢰도: **중간**
- 근거 수준: **B + D**
- 입력: 사용자의 `purpose`, 아이템 종류, 격식도, 활동·기능 태그
- 규칙:
  - `purpose`와 아이템 종류의 적합성, 목적별 격식 범위, 필요한 경우 활동·기능 적합성을 결합한다.
  - 상황 적합도는 `desired_style`과 분리한다. 예를 들어 캐주얼 스타일에는 맞는 후드티도 데이트·면접 상황 적합도는 낮게 평가할 수 있다.
  - 상의와 하의를 따로 평가해 어느 아이템이 목적과 어긋나는지 진단한다.
  - 상품의 목적 태그는 보조 증거로 사용하며, 아이템 종류상 강한 부적합을 태그 하나로 뒤집지 않는다.
- 초기 계산식:
  - 일반 목적: `상황 적합도 = 0.65 × 아이템-목적 적합성 + 0.35 × 격식 적합성`
  - 여행·높은 활동량: `0.55 × 아이템-목적 + 0.30 × 격식 + 0.15 × 활동·기능`
- 주의: 목적별 아이템 점수표는 서비스 가설이므로 사용자 평가 데이터로 지속 보정한다.

## R-CAT-01 목적에 필요한 의류 슬롯을 먼저 충족한다

- 신뢰도: **높음**
- 근거 수준: **B + D**
- 규칙:
  - 상·하의 코디는 상의, 하의, 신발을 기본 슬롯으로 확인한다.
  - 원피스나 점프슈트는 상·하의 슬롯을 하나의 전신 슬롯으로 대체한다.
  - 추운 날씨나 공식 드레스코드처럼 아우터가 필요한 상황은 아우터를 필수 슬롯으로 올릴 수 있다.
- 결과: 필수 슬롯이 누락되면 낮은 점수를 주는 대신 `코디 미완성`으로 표시한다.

## R-CAT-02 계절·기능·레이어 구조가 충돌하는 조합을 감점한다

- 신뢰도: **중간**
- 근거 수준: **B + D**
- 감점 후보:
  - 같은 위치에 기능이 겹치는 후드 위에 또 다른 두꺼운 후드를 입는 조합
  - 특별한 의도 없이 매우 두꺼운 패딩과 얇은 여름용 하의를 조합한 경우
  - 정장 셔츠와 운동용 트레이닝 하의처럼 목적과 기능이 크게 충돌하는 경우
- 예외:
  - 실내외 온도 차, 스포츠 믹스, 레이어드 스타일처럼 설명 가능한 의도가 있는 경우

# 5. 핏과 실루엣 규칙

## R-SIL-01 한쪽의 볼륨이 크다면 다른 쪽은 정돈한다

- 신뢰도: **높음**
- 근거 수준: **B + C**
- 추천:
  - 와이드나 플레어 하의에는 크롭, 턱인, 슬림 또는 레귤러핏 상의를 우선한다.
  - 오버핏 상의에는 스트레이트나 테이퍼드 하의를 우선한다.
- 감점 후보: 상·하의가 모두 크고 길어 허리선과 중심점이 사라지는 조합
- 예외: 스트리트, 힙합, 릴랙스드 스타일에서는 상·하의가 모두 여유로운 조합을 허용한다.

## R-SIL-02 너무 조이거나 지나치게 남는 핏을 감점한다

- 신뢰도: **높음**
- 근거 수준: **B + C**
- 감점 후보:
  - 단추 사이가 벌어지거나 어깨선이 끌리는 경우
  - 밑위, 허벅지와 관절 부위에 움직임을 방해하는 당김이 있는 경우
  - 소매나 바짓단이 과도하게 남아 의도하지 않은 큰 주름이 생기는 경우
- 예외: 드레이프, 셔링, 스태킹처럼 주름 자체가 디자인인 경우
- 주의: 오버핏은 단순히 큰 사이즈가 아니라 어깨, 소매와 총장이 의도적으로 설계된 상품인지 확인한다.

## R-SIL-03 허리선으로 상·하체 비율을 조절한다

- 신뢰도: **중간**
- 근거 수준: **B + C**
- 조건: 사용자가 다리가 길어 보이거나 허리선이 분명한 실루엣을 원하는 경우
- 추천:
  - 하이웨이스트 하의와 짧은 상의 또는 턱인을 제안한다.
  - 벨트나 재킷의 여밈 위치로 허리 기준점을 만든다.
- 예외: 로우라이즈나 롱앤린 실루엣이 사용자의 취향이면 허리선을 높이지 않는다.

## R-SIL-04 레이어드할 때 밑단 관계를 확인한다

- 신뢰도: **중간**
- 근거 수준: **B + C**
- 추천:
  - 안쪽 옷이 깔끔하게 숨겨지거나 길이 차이가 의도적으로 보이게 한다.
  - 목, 손목, 밑단 중 한두 곳에서만 레이어를 보여준다.
- 감점 후보:
  - 안쪽 상의가 불규칙하게 조금씩 노출되는 경우
  - 두꺼운 옷이 상체에 여러 겹 몰려 활동성과 균형을 해치는 경우
- 예외: 그런지, 디컨스트럭티드처럼 불규칙한 기장이 의도된 경우

## R-SIL-05 옷의 크기뿐 아니라 시각적 무게를 비교한다

- 신뢰도: **중간**
- 근거 수준: **B + C**
- 규칙:
  - 어두운색, 두꺼운 소재, 큰 패턴, 광택, 포켓과 장식도 시각적 볼륨으로 계산한다.
  - 두꺼운 아우터에는 이를 받쳐 줄 신발이나 정돈된 하의를 연결한다.
  - 하의에 큰 카고 포켓이나 강한 패턴이 있다면 상의 장식을 줄인다.

## R-SIL-06 상·하의 분할 비율은 사용자 목표에 맞게 평가한다

- 신뢰도: **중간**
- 근거 수준: **C + D**
- 규칙:
  - 상의 밑단과 하의 허리선이 만드는 분할점을 연속적인 비율로 계산한다.
  - 다리가 길어 보이는 목표에는 상의가 짧고 하의 비중이 큰 분할을 우선 탐색한다.
  - 1:2 또는 2:1 비율은 안정적인 후보로 사용할 수 있지만 절대적인 정답으로 두지 않는다.
  - 크롭, 턱인과 하이웨이스트는 각각 따로 중복 가점하지 않고 분할점 변화에 반영한다.
- 예외: 1:1 분할, 로우라이즈와 긴 상의를 의도적으로 선택한 스타일

# 6. 색상 분석과 조합 규칙

## R-COL-01 무채색과 저채도 색을 기본 연결색으로 사용한다

- 신뢰도: **높음**
- 근거 수준: **B + C**
- 기본 연결색 후보: 블랙, 화이트, 그레이, 네이비, 베이지, 브라운
- 추천: 강한 색상의 옷이 하나 있다면 나머지는 연결색으로 받친다.
- 예외: 컬러 블로킹이나 맥시멀리즘을 원하는 경우 강한 색을 여러 개 허용한다.
- 주의: 기본색은 실패 가능성이 낮은 후보일 뿐 자동 정답이 아니다.

## R-COL-02 같은 색 계열은 명도·채도·소재 차이로 구분한다

- 신뢰도: **높음**
- 근거 수준: **B + C**
- 추천:
  - 톤온톤 코디는 밝기나 채도 단계를 다르게 사용한다.
  - 니트, 데님, 가죽처럼 질감을 달리해 경계를 만든다.
- 감점 후보: 색과 소재가 거의 같지만 미세하게 어긋나 우연히 맞춘 것처럼 보이는 조합
- 예외: 의도적인 셋업, 유니폼형 스타일과 질감이 살아 있는 올블랙 코디

## R-COL-03 유사색은 안정적으로, 보색은 강한 포인트로 취급한다

- 신뢰도: **높음**
- 근거 수준: **B + C**
- 추천:
  - 색상환에서 가까운 색은 부드럽고 안정적인 후보로 둔다.
  - 반대편에 가까운 색은 둘 다 강조되므로 면적을 다르게 하거나 한쪽을 액세서리로 줄인다.
- 주의: 색상환의 각도만으로 조화를 확정하지 않고 명도, 채도, 면적과 목적을 함께 본다.

## R-COL-04 포인트색의 주인공을 정한다

- 신뢰도: **높음**
- 근거 수준: **B + C**
- 추천:
  - 포인트 의류가 있으면 신발과 가방은 비교적 중립적으로 둔다.
  - 기본 착장에는 포인트 가방, 신발 또는 스카프 중 하나를 추가할 수 있다.
- 감점 후보: 상의, 하의, 신발과 가방이 모두 다른 강한 색으로 같은 비중에서 경쟁하는 경우
- 예외: 대담한 컬러 블로킹을 요청한 경우

## R-COL-05 데님을 기본색처럼 연결할 수 있다

- 신뢰도: **중간**
- 근거 수준: **B + C**
- 추천: 데님 하의는 기본색과 포인트색 후보에 폭넓게 연결한다.
- 데님온데님: 워시, 명도, 핏 또는 소재감 중 하나 이상에 차이를 준다.

## R-COL-06 포인트색을 작은 면적으로 한 번 반복할 수 있다

- 신뢰도: **중간**
- 근거 수준: **B + C**
- 추천: 상의의 로고색이나 패턴 안의 색을 신발, 가방, 양말 중 한 곳에서 반복한다.
- 감점 후보: 모든 액세서리를 같은 색으로 강제로 맞춰 지나치게 세트처럼 보이는 경우

## R-COL-07 색 이름뿐 아니라 색이 차지하는 면적을 평가한다

- 신뢰도: **높음**
- 근거 수준: **A**
- 규칙:
  - 각 아이템의 주색, 보조색과 포인트색이 차지하는 면적을 계산한다.
  - 강한 색 두 개가 비슷한 면적에서 경쟁하면 한쪽 면적을 줄이는 후보를 탐색한다.
  - 상·하의 색 면적이 약 1:1.6 또는 1:2인 조합을 안정적인 후보 중 하나로 탐색할 수 있다.
- 예외: 셋업, 투톤 블로킹과 강한 대비가 의도된 스타일
- 주의: 특정 비율을 모든 코디의 황금비율로 고정하지 않는다.

## R-COL-08 선호색·보유 옷·목적을 함께 평가한다

- 신뢰도: **높음**
- 근거 수준: **A**
- 규칙:
  - 선호색만 보지 않고 보유 옷과의 조화, 장소·상황, 사용자 선호를 함께 점수화한다.
  - 점수가 비슷하면 사용자가 이미 가진 옷과 더 많이 연결되는 색을 우선한다.

## R-COL-09 의류별 대표색과 역할을 분리해 추출한다

- 신뢰도: **중간**
- 근거 수준: **D**
- 처리 순서:
  1. 의류 파싱으로 상의, 하의, 아우터, 신발과 가방 영역을 분리한다.
  2. 배경, 피부, 머리카락, 깊은 그림자와 반사 노이즈를 제외한다.
  3. 각 아이템의 픽셀을 CIELAB 또는 CIELCh 공간에서 군집화한다.
  4. 면적이 가장 큰 색을 주색, 다음 색을 보조색, 작지만 시각적으로 강한 색을 포인트색으로 구분한다.
  5. 작은 로고, 지퍼 반사와 그림자는 노이즈로 처리하되 실제 포인트 디자인은 유지한다.
- 주의: 전체 사진에서 색을 한 번에 세지 않고 아이템별 색과 전체 코디의 색 역할을 모두 저장한다.

## R-COL-10 주요 색상 수는 목적과 스타일에 맞게 평가한다

- 신뢰도: **중간**
- 근거 수준: **B + D**
- 규칙:
  - 2~3개의 주요 색은 안정적인 시작점으로 사용할 수 있다.
  - 무채색, 같은 색의 명도 변화와 작은 포인트는 서로 다른 주요 색으로 과도하게 세지 않는다.
  - 4개 이상이어도 공통색, 면적 위계와 스타일 의도가 분명하면 감점하지 않을 수 있다.
  - 포멀·미니멀은 색 수와 포인트 강도 기준을 엄격하게, 스트리트·맥시멀은 완화한다.
- 금지: 색이 3개를 넘는다는 이유만으로 큰 고정 감점을 주는 방식

## R-COL-11 무채색과 저채도 코디는 색상환보다 명도·질감·깊이로 평가한다

- 신뢰도: **높음**
- 근거 수준: **B + C**
- 규칙:
  - 채도가 매우 낮은 색은 색상환 각도보다 명도 차이, 소재와 면적을 중심으로 평가한다.
  - 올블랙, 올화이트와 톤온톤은 명도 또는 질감 차이가 있으면 단색이라는 이유로 감점하지 않는다.
  - 모든 아이템이 거의 같은 RGB 값과 비슷한 표면을 가져 경계가 사라지면 시각적 깊이 항목에서만 소폭 감점한다.

## R-COL-12 작은 아이템의 색은 전체 코디와의 연결성을 평가한다

- 신뢰도: **중간**
- 근거 수준: **B + D**
- 대상: 양말, 모자, 가방, 신발, 스카프와 작은 액세서리
- 규칙:
  - 작은 아이템이 상의·하의·신발 중 하나의 색을 반복하거나 전체 팔레트의 연결색이면 가점한다.
  - 흰 양말이나 검은 양말을 모든 상황의 정답으로 두지 않는다.
  - 구두, 운동화, 샌들 등 신발 종류와 노출 정도, 격식과 스타일을 함께 본다.

## R-COL-13 색의 대중성을 색 자체의 고정 점수로 사용하지 않는다

- 신뢰도: **중간**
- 근거 수준: **A + D**
- 규칙:
  - 형광색이나 흔하지 않은 색이라는 이유만으로 고정 감점을 주지 않는다.
  - 실제 입기 쉬운지는 사용 목적, 보유 옷과의 조합 수, 사용자의 색 선호와 스타일 태그로 평가한다.
  - 국내 판매·검색 추세는 `유행 점수`로 별도 관리하고 색상 조화 점수에 섞지 않는다.
- 이유: 대중적인 색과 조화로운 색은 같은 개념이 아니며, 고정된 색별 점수는 개성과 문화·시즌 변화를 제대로 반영하기 어렵다.

# 7. 패턴·소재·복잡도 규칙

## R-PAT-01 강한 패턴은 한 영역을 주인공으로 둔다

- 신뢰도: **높음**
- 근거 수준: **A + B + C**
- 추천:
  - 패턴 상의에는 단색 하의를 우선한다.
  - 패턴 하의에는 형태가 간결한 단색 상의를 우선한다.
  - 두 패턴을 섞을 때는 공통색을 확보하고 패턴 크기나 밀도를 다르게 한다.
- 예외: 동일 패턴 셋업, 맥시멀리즘과 프레피 패턴 믹스

## R-PAT-02 디테일이 강한 옷에는 액세서리를 단순하게 한다

- 신뢰도: **높음**
- 근거 수준: **B + C**
- 조건: 큰 프린트, 프릴, 스팽글, 자수, 강한 절개 또는 광택이 있는 경우
- 추천: 작은 주얼리, 단색 가방과 간결한 신발을 우선한다.
- 감점 후보: 강한 의류, 큰 주얼리와 강한 가방이 동시에 같은 비중으로 경쟁하는 경우

## R-PAT-03 패턴의 종류뿐 아니라 크기·간격·대비를 분석한다

- 신뢰도: **높음**
- 근거 수준: **A**
- 분석 속성:
  - 패턴 종류와 개수
  - 반복 간격과 무늬 크기
  - 바탕색과 무늬색의 명도·채도 대비
  - 패턴이 차지하는 면적
- 규칙: 상·하의가 모두 패턴이면 공통색과 전체 포인트 강도를 확인한다.

## R-PAT-04 패턴 개수는 스케일과 스타일을 함께 평가한다

- 신뢰도: **중간**
- 근거 수준: **B + D**
- 규칙:
  - 강한 패턴 0~1개는 안정적인 기본 후보로 둔다.
  - 패턴 2개는 공통색이 있고 크기나 밀도 차이가 있으면 허용한다.
  - 강한 패턴이 3개 이상이면 기본적으로 복잡도를 높이되 맥시멀 스타일은 기준을 완화한다.
  - 동일 패턴 셋업은 여러 패턴이 아니라 하나의 통일된 디자인으로 처리한다.

## R-MAT-01 계절과 활동에 맞는 소재를 먼저 선택한다

- 신뢰도: **높음**
- 근거 수준: **A + B**
- 추천:
  - 덥고 습한 날에는 가볍고 통기성과 건조 편의성이 좋은 소재를 우선한다.
  - 추운 날에는 보온 소재와 바람을 막는 아우터를 우선한다.
  - 여행이나 장시간 이동에는 구김, 무게와 활동성을 함께 고려한다.
- 주의: 사진만으로 소재를 확정하기 어렵다면 상품 상세정보를 사용한다.

## R-MAT-02 같은 색 코디에는 질감 차이를 활용한다

- 신뢰도: **중간**
- 근거 수준: **B + C**
- 추천: 무광 니트와 매끈한 팬츠, 데님과 가죽처럼 표면 차이를 준다.
- 감점 후보: 상·하의가 모두 두껍고 거친 소재라 전체 시각적 무게와 활동성이 과도해지는 경우

## R-CMP-01 코디의 포인트 개수는 산 모양으로 평가한다

- 신뢰도: **중간**
- 근거 수준: **B + D**
- 포인트 요소: 강조색, 강한 패턴, 큰 액세서리, 특이한 실루엣과 강한 광택
- 규칙:
  - 포인트가 전혀 없으면 사용 목적에 따라 작은 액세서리나 질감 차이를 제안할 수 있다.
  - 포인트 1~2개는 안정적인 기본 범위로 둔다.
  - 3개 이상이면 같은 영역에서 시선을 경쟁하는지 확인한다.
  - 미니멀·포멀은 적정 복잡도를 낮게, 데일리·데이트는 낮음~보통, 스트리트·페스티벌은 보통~높게 둔다.
- 주의: 같은 요소를 색상, 패턴과 복잡도 축에서 반복 감점하지 않도록 복잡도 배점을 작게 유지한다.

## R-CMP-02 무난함과 스타일링 완성도를 같은 점수로 보지 않는다

- 신뢰도: **중간**
- 근거 수준: **B + D**
- 문제: 무채색·무지·레귤러핏처럼 충돌이 적은 조합은 실패 가능성이 낮지만, 그것만으로 스타일링 완성도가 높은 것은 아니다.
- 규칙:
  - 색상 안정성과 스타일링 완성도를 별도 축으로 계산한다.
  - 비율과 볼륨의 중심, 소재의 깊이, 한 영역에 정리된 색·패턴, 넥라인·어깨 구조 또는 레이어 중 하나 이상에서 의도가 읽히는지 확인한다.
  - 위 요소가 전혀 없으면 색상과 TPO 점수가 높더라도 현재 착장 총점이 자동으로 최상위가 되지 않게 한다.
  - 강한 색이나 패턴의 존재 자체에는 가점하지 않고, 다른 요소와 경쟁하지 않도록 위계가 정리됐을 때 가점한다.
- 미니멀·포멀 예외:
  - 포인트 부재를 감점하지 않는다.
  - 대신 톤 차이, 소재 대비, 정돈된 선, 의도적인 여유량과 비율 중 하나 이상이 확인되면 높은 완성도를 허용한다.
- 이중 감점 방지: 무지·무채색이라는 같은 이유를 색상, 패턴과 완성도에서 반복 감점하지 않는다.

## R-CMP-03 상·하의 조화는 관찰 가능한 네 관계로 계산한다

- 신뢰도: **중간**
- 근거 수준: **B + D**
- 배점: **실루엣 35% + 격식 25% + 색상 25% + 패턴·소재 15%**
- 판정: 네 하위 점수를 가중 평균한 조화점수가 **85점 이상이면 통과**한다.
- 실루엣 기준:
  - **롱 오버핏 상의 + 롱 와이드 하의**는 연속된 볼륨을 의도한 최근 트렌드 실루엣으로 보고 높은 점수를 준다.
  - **오버핏 상의 + 스트레이트 하의**는 충돌이 적은 안정적인 기본 조합이지만, 그 이유만으로 고득점시키지 않고 평균권으로 둔다.
  - 상·하의가 모두 크다는 이유만으로 자동 감점하지 않는다. 기장과 볼륨이 하나의 의도로 이어지는지 본다.
- 격식 기준: 상·하의의 격식도 단계 차이를 계산하되 스트리트·맥시멀처럼 의도된 믹스 스타일은 완화한다.
- 색상 기준: 무채색 연결, 톤온톤, 유사색, 대비색 등 실제 색 관계를 계산한다.
- 패턴·소재 기준: 두 패턴의 시선 경쟁과 같은 색 코디의 질감 차이를 함께 계산한다.
- 진단 원칙: 상의와 하의의 개별 적합도가 모두 통과해도 조화점수가 85점 미만이면 전체 착장은 통과하지 않는다. 이때 어느 한쪽을 임의로 탓하지 않고 상의·하의 교체 후보의 Delta를 비교한다.

- 예외: 사용자가 로우라이즈, 바디핏, 짧은 하의 또는 의도적인 1:1 분할을 선호하면 관련 감점을 완화한다.

- 저장 항목: 적용 시작일, 종료일, 대상 연령대, 스타일 태그, 지역과 출처 날짜
- 규칙:
  - 국내 쇼핑몰 신상품·판매 추세와 국내 전문가 콘텐츠를 주기적으로 갱신한다.
  - 사용자가 트렌디한 스타일을 원할 때만 유행 점수를 높인다.
  - 미니멀이나 클래식 취향의 사용자에게 유행을 강요하지 않는다.

# 12. 기본 감점 조합

다음 항목은 금지 규칙이 아니라 별도의 스타일 의도가 없을 때만 감점한다.

1. 상·하의가 모두 크고 길어 중심점이 전혀 없는 조합
2. 여러 강한 색이 같은 면적으로 경쟁하고 연결색이 없는 조합
3. 크기와 대비가 비슷한 두 패턴이 공통색 없이 충돌하는 조합
4. 큰 프린트, 큰 주얼리와 강한 가방을 동시에 사용한 조합
5. 레이어드 밑단이 불규칙하게 조금씩 노출되는 조합
6. 목적과 계절보다 유행을 우선해 활동하기 어려운 조합
7. 어깨, 단추, 밑위와 허벅지에서 당김이 분명한 옷
8. 바짓단이 바닥에 끌리거나 신발 위에 과도하게 쌓이는 조합
9. 가방과 신발 색만 맞고 전체 격식이나 소재가 크게 어긋난 조합
10. 사용자가 강조하고 싶지 않은 위치에 강한 색, 광택과 큰 패턴이 집중된 조합
11. 필수 슬롯이 빠졌거나 계절·기능이 뚜렷하게 충돌하는 조합
12. 분석 신뢰도가 낮은데도 강한 감점이나 단정적인 설명을 제공하는 경우

## 현재 착장 점수

`CURRENT OUTFIT SCORE`는 상품 후보의 안전성 점수와 분리한다. 지금 입은 옷은 무난함만으로 고득점하지 않도록 실루엣·체형 보완과 스타일링 의도의 비중을 높인다.

### 2026-08-26 개편 — 상·하의 진단 행렬

사용자에게는 상의와 하의를 각각 다음 세 축으로 보여준다.

| 대상 | 체형 적합도 | 상황 적합도 | 스타일 적합도 |
|---|---:|---:|---:|
| 상의 | 0~100 | 0~100 | 0~100 |
| 하의 | 0~100 | 0~100 | 0~100 |

- 체형 적합도: 핏·기장·구조가 분석된 체형과 목표 비율을 만드는 정도
- 상황 적합도: `purpose`와 아이템 종류·격식·활동성의 일치 정도
- 스타일 적합도: 아이템별 스타일과 `desired_style`의 일치 정도
- 항목별 합성: `0.35 × 체형 + 0.40 × 상황 + 0.25 × 스타일`
- 2×3 각 셀은 **85점 이상이면 통과**, 85점 미만이면 개선 대상으로 표시한다.
- 현재 착장 유지는 `전체 총점 85점 이상`이면서 평가 가능한 2×3 셀이 모두 통과한 경우에만 허용한다.
- 전체 점수: 상의와 하의 합성점수의 평균에서 명확한 상·하의 충돌만 최대 12점 감점
- 추상적인 `패션 조화`는 사용자 점수축에서 제거하고, 볼륨·패턴·격식의 분명한 충돌을 내부 패널티로만 유지한다.
- 현재 착장과 후보 착장은 반드시 같은 진단식으로 계산해 Delta Score가 같은 척도를 갖게 한다.
- 추천 효용: `추천 후 점수 - 현재 점수 - 4 × 변경 아이템 수`
- 예상 개선폭이 4점 미만이거나 변경 비용을 이기지 못하면 현재 착장을 유지한다.

# 15. 검증과 개선 방법

현재 규칙은 학습 정답이 아니라 전문가 검토 전의 규칙 후보 데이터다. 다음 순서로 검증한다.

1. 패션 전공자나 스타일리스트 2명 이상이 각 규칙에 `동의`, `조건부 동의`, `반대`를 표시한다.
2. 규칙별로 좋은 조합과 개선이 필요한 조합 이미지를 최소 20쌍씩 수집한다.
3. 여러 평가자가 같은 코디를 독립적으로 평가해 규칙별 합의도를 계산한다.
4. 합의도가 낮은 규칙은 조건과 예외를 세분화하거나 배점을 낮춘다.
5. 초기 가중치는 규칙 기반으로 사용하고 실제 사용자 피드백이 쌓이면 학습 기반 순위 모델로 보정한다.
6. 목적·안전·날씨·재고 같은 제약은 개인 취향 모델과 분리해 유지한다.
7. 성별, 연령대와 스타일별로 추천 품질의 편향을 확인한다.

### 우선 검증이 필요한 팀 가설

- 주요 색상 2~3개가 가장 안정적인지
- 격식도 1~5 태깅과 아이템 간 허용 거리
- 1:2 또는 2:1 분할 비율의 사용자 선호도
- 포인트 1~2개가 목적별로 적절한지
- 상·하의 핏 조합별 점수 행렬
- 작은 아이템의 색 반복이 실제 선호도를 높이는지

# 16. 통합 과정에서 수정한 팀 제안

| 오버핏 상의와 오버핏 하의 일괄 감점 | 스트리트·릴랙스드 스타일 예외 적용 | 스타일 의도가 있는 볼륨 조합을 허용하기 위해서다. |
| 1:2 또는 2:1 비율에 고정 가점 | 사용자 목표에 따른 연속 점수 | 특정 비율을 모든 체형과 스타일의 정답으로 만들지 않기 위해서다. |
| 포인트가 없으면 무조건 감점 | 미니멀 취향은 예외 처리 | 단순함 자체가 사용자의 의도일 수 있기 때문이다. |
| 항목마다 독립적으로 감점 누적 | 한 원인은 한 축에서 우선 평가 | 같은 패턴이나 소재를 여러 항목에서 중복 감점하는 것을 막기 위해서다. |
