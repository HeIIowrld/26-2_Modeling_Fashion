# 유튜브 패션 사진 자동 수집

룩북·코디 영상에서 **정면 전신** 프레임만 골라내 성별 폴더로 저장한다.
메인 README 2단계(체형·자세 분석)가 요구하는 입력 조건 — 정면 전신, 몸과 옷의
경계가 뚜렷한 이미지 — 을 그대로 통과 기준으로 사용한다.

## 실행

```bash
python -m pip install -r collect/requirements.txt
python collect/setup.py                          # 최초 1회 (Pose 모델 + ffmpeg 준비)
python collect/discover_channels.py --write      # 패션 채널 찾아 sources.json 에 반영
python collect/collect.py --target 50            # 남/여 50장씩
```

결과:

```
data/images/male/    male_001_<영상ID>_<프레임>.jpg
data/images/female/  female_001_...
data/manifest.csv    파일명, 성별, 출처 URL, 영상 내 시각, 해상도
```

원본 영상은 임시 폴더(`%TEMP%\fashion_collect_video`)에 받아 처리 후 삭제한다.
프로젝트 경로에 한글이 있어 OpenCV·MediaPipe가 파일을 못 여는 문제가 있어,
영상은 ASCII 경로에서 다루고 이미지는 `imencode`/`imdecode`로 입출력한다.

## 파이프라인

| 단계 | 내용 |
| --- | --- |
| 1. 소스 해석 | `sources.json`의 검색어·URL을 영상 목록으로 펼침 (yt-dlp) |
| 2. 다운로드 | 오디오 없이 영상만 (병합 불필요), 20초~25분 길이만 |
| 3. 샘플링 | 1.5초 간격으로 프레임 추출, 인트로·아웃트로 구간 제외 |
| 4. 자세 필터 | MediaPipe PoseLandmarker(heavy) 33개 관절로 정면 전신 판정 |
| 5. 중복 제거 | dHash 해밍거리 12 미만이면 같은 컷으로 간주 |
| 6. 크롭·저장 | 인물 박스를 3:4로 확장해 JPEG 95 품질 저장 |

### 통과 기준 (`Criteria`)

- **전신**: 어깨·골반·무릎·발목 8개 관절 visibility ≥ 0.55, 머리·발이 프레임 안
- **정면**: 어깨너비/상체길이 ≥ 0.26, 양쪽 귀 노출, 코가 어깨 사이
- **자세**: 어깨 기울기 ≤ 0.28, 무릎이 골반 아래 (서 있는 자세)
- **크기**: 인물 높이가 프레임의 55% 이상, 크롭 결과 480px 이상
- **화질**: 인물 영역 Laplacian 분산 ≥ 55 (흔들린 프레임 제외)
- **단독**: 높이 38%를 넘는 인물이 둘 이상이면 제외
- **자막**: 하단에 박힌 흰 글자가 한 줄 이상이면 제외 (의류 파싱 방해)

각 프레임의 탈락 사유는 영상별로 집계되어 로그에 찍힌다.

```
프레임 210개 검사 -> 6장 채택 | 탈락: 자막:88, 전신아님:52, 중복:31, 측면/뒷면:19
```

## 소스 채널 (`discover_channels.py`)

검색어를 그때그때 쓰는 것보다 **패션 채널을 고정**하는 편이 좋다. 같은 채널은
촬영 구도·조명이 일정해 정면 전신 통과율이 높고, 스타일 계열도 일관된다.

`discover_channels.py`는 채널명을 추측하지 않는다. 탐색용 검색어로 영상을 훑어
어떤 채널이 반복해 잡히는지 세고, 제목에 룩북 관련 단어(`룩북`, `코디`, `outfit` …)가
있으면 가점, 하울·브이로그·언박싱 등 정면 전신이 잘 안 나오는 유형이면 감점해
상위 채널만 남긴다. 즉 실제로 존재하는 채널만 들어간다.

```bash
python collect/discover_channels.py                     # 후보만 확인
python collect/discover_channels.py --verify --write    # 실측 검증 후 반영 (권장)
python collect/discover_channels.py --gender male --top 10 --verify --write
```

**`--verify`를 쓰는 편이 좋다.** 제목만으로는 스튜디오 룩북과 토크·팁 영상을
구분할 수 없다. 실측에서 8개 후보 중 6개가 탈락한 적이 있다.

```
[탈락] 너드킹 Nerd King: 전신 0프레임 / 영상 1편
[통과] Korean Gents: 전신 2프레임 / 영상 1편
```

채널당 360p로 1편만 받아 16프레임을 확인하므로 1~2분이면 끝난다.

> **AI 룩북 채널 주의.** 검증을 통과해도 AI로 생성된 룩북 채널이 섞일 수 있다.
> 실제 인물이 아니라 체형·착장 학습 데이터로 쓸 수 없으므로 `BAD_WORDS`에
> `ai lookbook`, `가상인간` 등을 넣어 막아두었지만, 새 채널을 추가할 때는
> 영상을 한 번 확인하는 것이 안전하다.

`--write`는 채널을 목록 **앞**에 넣고 기존 검색어는 예비 소스로 뒤에 남긴다.
채널에서 목표 장수를 채우면 검색어는 쓰이지 않고, 모자랄 때만 이어서 사용된다.

한 번 돌린 뒤에는 `report.py`로 채널별 실제 수율을 확인해 정리한다.

```bash
python collect/report.py collect/run_male.log collect/run_female.log
```

```
소스                                       영상   건너뜀    프레임   수집
소신사장 SoshinTV                             8     0    673   46
선 빈                                       1     1      0    0
세빈 SEBIN                                  2     2      0    0
```

수율이 0인 채널은 빼고, 잘 나오는 채널의 `max_videos`를 올린다. 실제로 여성
50장 중 46장이 한 채널에서 나왔다 — **좋은 채널 하나를 찾는 편이 검색어 열 개보다 낫다.**

## 수집량이 부족할 때

로그 마지막에 소스 소진 안내가 뜨면 아래 순서로 조정한다.

1. 채널을 늘린다. `python collect/discover_channels.py --top 10 --write` 로 후보를
   더 뽑거나, 아는 채널을 직접 추가한다.
   ```json
   { "type": "url", "url": "https://www.youtube.com/@채널명/videos", "max_videos": 12 }
   ```
2. `--per-video 10` — 영상 1편에서 더 많이 뽑는다 (같은 옷 반복 위험).
3. `--min-person-height 0.45` — 인물이 작게 잡힌 프레임도 허용한다.
4. `--allow-subtitle` — 자막 필터를 끈다. 탈락 사유 1위가 `자막`일 때만 권장.

이어서 실행하면 기존 이미지의 해시를 먼저 읽어 **중복 없이 누적**되므로,
옵션을 바꿔 여러 번 돌려도 된다.

## 주요 옵션

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `--target` | 50 | 성별당 목표 장수 |
| `--per-video` | 6 | 영상 1편당 최대 장수 (다양성 확보) |
| `--interval` | 1.5 | 프레임 샘플링 간격(초) |
| `--gender` | 둘 다 | `male` / `female` 한쪽만 수집 |
| `--model` | heavy | `lite`로 바꾸면 5배 빠르지만 정확도 하락 |
| `--max-height` | 1080 | 다운로드 최대 해상도 |
| `--keep-video` | 끔 | 원본 영상 보존 (기준을 바꿔 재검사할 때) |

## 성별 라벨

영상 단위로 라벨을 붙인다. 룩북 영상은 등장인물 성별이 고정되어 있어
`sources.json`의 `male` / `female` 목록에 넣는 것만으로 라벨이 정해진다.
이미지 기반 성별 분류기를 쓰지 않으므로 오분류가 구조적으로 발생하지 않지만,
남녀가 함께 나오는 커플룩 영상은 넣지 않는 것이 좋다.

## 품질 검사 (`qa.py`)

수집 기준을 바꿔가며 여러 번 돌리면 이전 기준의 결과가 섞인다. 마지막에 한 번
전수 재검사를 돌리는 것을 권한다.

```bash
python collect/qa.py           # 검사만 (data/qa_failures.csv 생성)
python collect/qa.py --move    # 불합격을 data/rejected/ 로 이동
```

크롭된 이미지를 다시 판정하고, 출처 영상 제목이 제외 대상(AI 룩북 등)인지도
확인한다. 실제로 첫 100장 중 34장이 불합격이었다.

| 사유 | 장수 |
| --- | --- |
| 전신아님 (얼굴 모자이크 등으로 관절 검출 실패) | 24 |
| 인물없음 · 머리/발 잘림 · 다중인물 | 10 |

`--move` 후 다시 `collect.py`를 돌리면 부족분을 채운다. 이때 `data/rejected/`의
해시도 중복 검사에 포함되므로 **같은 프레임이 다시 들어오지 않는다**.

## 자동 필터로 거르지 못하는 것

다음은 사람이 눈으로 확인해야 한다.

- **편집 그래픽 프레임**: 인물을 오려 붙이고 옆에 상품 이미지·텍스트를 배치한
  화면. 인물 자체는 정면 전신이라 통과한다. 이미지 전체 텍스트 검출을 시도해
  봤으나 이런 프레임을 잡지 못하고 정상 이미지에 오탐만 나서 넣지 않았다.
  `총정리`, `모음` 류의 편집 영상에서 주로 나온다.
- **얼굴 모자이크**: 길거리 촬영 영상은 초상권 처리로 얼굴이 흐려져 있다.
  `qa.py`가 관절 검출 실패로 잡아내는 편이지만 전부는 아니다.
- **같은 옷 반복**: 한 영상에서 같은 착장이 여러 각도로 나온다. dHash 로
  걸러내지만 조명·배경이 크게 바뀌면 통과한다. `--per-video` 를 낮추면 줄어든다.

## 데이터 이용 주의

유튜브 약관상 영상 다운로드는 제한되어 있다. 수집물은 연구·모델 개발용
내부 데이터로만 쓰고 재배포하지 않는 것을 전제로 한다. `manifest.csv`에
출처 URL과 영상 내 시각이 남으므로 필요할 때 원본을 추적하거나 삭제할 수 있다.
공개 배포용 데이터셋이 필요하다면 DeepFashion, Fashionpedia 같은 라이선스가
명확한 공개 데이터셋을 함께 검토한다.
